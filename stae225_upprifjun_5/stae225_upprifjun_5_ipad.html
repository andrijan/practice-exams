Formúlur

Núllþáttareglan: ef $a \cdot b = 0$ þá er $a = 0$ eða $b = 0$.
Lausnarformúlan: $ax^2 + bx + c = 0$ hefur lausnirnar $x = \dfrac{-b \pm \sqrt{d}}{2a}$ þar sem $d = b^2 - 4ac$. Ef $d > 0$ eru lausnirnar tvær, ef $d = 0$ ein og ef $d < 0$ engin.
Fleygboginn $y = ax^2 + bx + c$: samhverfuás $x = -\dfrac{b}{2a}$; opnast upp ef $a > 0$, niður ef $a < 0$.
Leifareglan: leifin þegar $f(x)$ er deilt með $x - a$ er $f(a)$.
Þáttunarreglan: ef $f(a) = 0$ þá er $x - a$ þáttur í $f(x)$.
Biltákn: $[a,\ b]$ tekur endapunktana með, $]a,\ b[$ ekki; $[a,\ \infty[$ er allt frá $a$ og upp úr.

Dæmi

1. Leystu jöfnurnar nákvæmt og strikaðu undir lokasvarið.
a. $(x + 1)(4 - x) = 0$
$\displaystyle (x + 1)(4 - x) = 0$
Núllþáttareglan gefur$\displaystyle x + 1 = 0 \quad\text{eða}\quad 4 - x = 0$
svo að$\displaystyle x = -1 \quad\text{eða}\quad x = 4$
Svar: $x = -1$ eða $x = 4$
b. $3x^2 - 2x + 4 = 0$
Jafnan er á staðlaða forminu $ax^2 + bx + c = 0$ með$\displaystyle 3x^{2} - 2x + 4 = 0$
$\displaystyle a = 3,\quad b = -2,\quad c = 4$
Aðgreinirinn:$\displaystyle d = (-2)^{2} - 4\cdot 3\cdot 4 = 4 - 48 = -44$
$d = -44 < 0$: það er engin rauntala sem hefur neikvæðan ferning, svo jafnan hefur enga lausn.
Svar: Engin lausn (í mengi rauntalna).
c. $x^2 = 6x$
$\displaystyle x^{2} = 6x$
Flytjum $6x$ yfir á vinstri hlið (deilum ekki með $x$, þá týnist lausnin $x = 0$):$\displaystyle x^{2} - 6x = 0$
Tökum $x$ út fyrir sviga:$\displaystyle x^{2} - 6x = x(x - 6)$
Núllþáttareglan gefur$\displaystyle x = 0 \quad\text{eða}\quad x - 6 = 0$
svo að$\displaystyle x = 0 \quad\text{eða}\quad x = 6$
Svar: $x = 0$ eða $x = 6$
d. $\sqrt{x + 6} = x + 4$
$\displaystyle \sqrt{x + 6} = x + 4$
Hefjum báðar hliðar í annað veldi (þetta getur búið til falskar lausnir):$\displaystyle x + 6 = (x + 4)^{2}$
Margföldum upp úr sviganum:$\displaystyle (x + 4)^{2} = x^{2} + 8x + 16$
svo að$\displaystyle x + 6 = x^{2} + 8x + 16$
Flytjum allt yfir á eina hlið:$\displaystyle x^{2} + 7x + 10 = 0$
Þáttum:$\displaystyle x^{2} + 7x + 10 = (x + 2)(x + 5)$
Núllþáttareglan gefur$\displaystyle x = -2 \quad\text{eða}\quad x = -5$
Prófun, $x = -2$:$\displaystyle \text{vinstri hlið: } \sqrt{-2 + 6} = 2, \quad \text{hægri hlið: } -2 + 4 = 2, \quad 2 = 2$✓ lausnin stenst.
Prófun, $x = -5$:$\displaystyle \text{vinstri hlið: } \sqrt{-5 + 6} = 1, \quad \text{hægri hlið: } -5 + 4 = -1, \quad 1 \neq -1$✗ fölsk lausn — höfnum henni.
Svar: $x = -2$ ($x = -5$ er fölsk lausn)
e. $x^4 + 2x^2 - 3 = 0$
Setjum $u = x^2$. Þá er $x^4 = u^2$ og jafnan verður$\displaystyle u^{2} + 2u - 3 = 0$
Tölurnar $-1$ og $3$ hafa margfeldið $-3$ og summuna $2$:$\displaystyle u^{2} + 2u - 3 = (u - 1)(u + 3)$
Núllþáttareglan gefur$\displaystyle u = 1 \quad\text{eða}\quad u = -3$
$u = x^2$ getur ekki verið neikvætt, svo $u = -3$ gefur enga lausn.
Skiptum $u$ út fyrir $x^2$:$\displaystyle x^{2} = 1$
Drögum ferningsrót af báðum hliðum:$\displaystyle x = \pm \sqrt{1} = \pm 1$
Svar: $x = \pm 1$
f. $3x^2 - 4 = 359$
$\displaystyle 3x^{2} - 4 = 359$
Leggjum $4$ við báðar hliðar:$\displaystyle 3x^{2} = 363$
Deilum með $3$:$\displaystyle x^{2} = \dfrac{363}{3} = 121$
Drögum ferningsrót af báðum hliðum:$\displaystyle x = \pm \sqrt{121} = \pm 11$
Svar: $x = \pm 11$
2. Notaðu aðferðina „að fylla í ferninginn“ til að leysa jöfnuna $x^2 + 6x - 8 = 0$.
$\displaystyle x^{2} + 6x - 8 = 0$
Flytjum fastaliðinn yfir á hægri hlið:$\displaystyle x^{2} + 6x = 8$
Helmingurinn af stuðli $x$ er $3$. Bætum $(3)^2 = 9$ við báðar hliðar:$\displaystyle x^{2} + 6x + 9 = 8 + 9$
Vinstri hliðin er fullkominn ferningur, $(x + 3)^2$:$\displaystyle (x + 3)^{2} = 17$
Drögum ferningsrót af báðum hliðum:$\displaystyle x + 3 = \pm \sqrt{17}$
Drögum $3$ frá báðum hliðum:$\displaystyle x = -3 \pm \sqrt{17}$
Svar: $x = -3 \pm \sqrt{17}$
3. Deildu með margliðudeilingu.
a. $(2x^3 - 3x^2 + 6) : (x - 4)$
Deilum fremsta lið með fremsta lið deilisins:$\displaystyle \dfrac{2x^{3}}{x} = 2x^{2}$
Margföldum deilinn með því:$\displaystyle 2x^{2}(x - 4) = 2x^{3} - 8x^{2}$
Drögum frá:$\displaystyle \left(2x^{3} - 3x^{2} + 6\right) - (2x^{3} - 8x^{2}) = 5x^{2} + 6$
Deilum fremsta lið með fremsta lið deilisins:$\displaystyle \dfrac{5x^{2}}{x} = 5x$
Margföldum deilinn með því:$\displaystyle 5x(x - 4) = 5x^{2} - 20x$
Drögum frá:$\displaystyle \left(5x^{2} + 6\right) - (5x^{2} - 20x) = 20x + 6$
Deilum fremsta lið með fremsta lið deilisins:$\displaystyle \dfrac{20x}{x} = 20$
Margföldum deilinn með því:$\displaystyle 20(x - 4) = 20x - 80$
Drögum frá:$\displaystyle \left(20x + 6\right) - (20x - 80) = 86$
Leifin $86$ er af lægra stigi en deilirinn, svo$\displaystyle \dfrac{2x^{3} - 3x^{2} + 6}{x - 4} = 2x^{2} + 5x + 20 + \dfrac{86}{x - 4}$
Svar: $2x^2 + 5x + 20 + \dfrac{86}{x - 4}$
b. $(3x^3 + 2x^2 - 7x + 2) : (x + 2)$
Deilum fremsta lið með fremsta lið deilisins:$\displaystyle \dfrac{3x^{3}}{x} = 3x^{2}$
Margföldum deilinn með því:$\displaystyle 3x^{2}(x + 2) = 3x^{3} + 6x^{2}$
Drögum frá:$\displaystyle \left(3x^{3} + 2x^{2} - 7x + 2\right) - (3x^{3} + 6x^{2}) = -4x^{2} - 7x + 2$
Deilum fremsta lið með fremsta lið deilisins:$\displaystyle \dfrac{-4x^{2}}{x} = -4x$
Margföldum deilinn með því:$\displaystyle -4x(x + 2) = -4x^{2} - 8x$
Drögum frá:$\displaystyle \left(-4x^{2} - 7x + 2\right) - (-4x^{2} - 8x) = x + 2$
Deilum fremsta lið með fremsta lið deilisins:$\displaystyle \dfrac{x}{x} = 1$
Margföldum deilinn með því:$\displaystyle 1(x + 2) = x + 2$
Drögum frá:$\displaystyle \left(x + 2\right) - (x + 2) = 0$
Leifin $0$ er af lægra stigi en deilirinn, svo$\displaystyle \dfrac{3x^{3} + 2x^{2} - 7x + 2}{x + 2} = 3x^{2} - 4x + 1$
Svar: $3x^2 - 4x + 1$
4. Gefinn er fleygboginn $f(x) = 2x^2 + 6x - 8$.
a. Finndu jöfnu samhverfuássins (sýndu útreikninga).
Samhverfuásinn er $x = -\dfrac{b}{2a}$ með $a = 2$ og $b = 6$:$\displaystyle x = \dfrac{-6}{2\cdot 2} = \dfrac{-6}{4} = -\tfrac{3}{2}$
Svar: $x = -1{,}5$
b. Finndu topppunktinn (sýndu útreikninga).
Topppunkturinn er á samhverfuásnum. Setjum $x = -1{,}5$ inn:$\displaystyle y = 2\cdot (-\tfrac{3}{2})^{2} + 6\cdot (-\tfrac{3}{2}) - 8 = \tfrac{9}{2} - 9 - 8 = -\tfrac{25}{2}$
$a = 2 > 0$, svo fleygboginn opnast upp og topppunkturinn er lægsti punkturinn.
Svar: $(-1{,}5;\ -12{,}5)$
c. Finndu skurðpunktana við $x$-ás (sýndu útreikninga).
Á $x$-ás er $y = 0$:$\displaystyle 2x^{2} + 6x - 8 = 0$
Tökum $2$ út fyrir sviga:$\displaystyle 2x^{2} + 6x - 8 = 2(x^{2} + 3x - 4)$
Tölurnar $4$ og $-1$ hafa margfeldið $-4$ og summuna $3$:$\displaystyle x^{2} + 3x - 4 = (x + 4)(x - 1)$
svo jafnan er$\displaystyle 2(x + 4)(x - 1) = 0$
Núllþáttareglan gefur$\displaystyle x + 4 = 0 \quad\text{eða}\quad x - 1 = 0$
svo að$\displaystyle x = -4 \quad\text{eða}\quad x = 1$
Svar: $(-4, 0)$ og $(1, 0)$
d. Finndu skurðpunktinn við $y$-ás.
Á $y$-ás er $x = 0$:$\displaystyle y = 2\cdot 0^{2} + 6\cdot 0 - 8 = -8$
Svar: $(0, -8)$
e. Teiknaðu fleygbogann eins nákvæmlega og þú getur (finndu aukapunkta).
Merkjum skurðpunktana og topppunktinn úr a–d lið. Reiknum nokkra aukapunkta:
$\displaystyle f(-5) = 2\cdot (-5)^{2} + 6\cdot (-5) - 8 = 50 - 30 - 8 = 12$
$\displaystyle f(-2) = 2\cdot (-2)^{2} + 6\cdot (-2) - 8 = 8 - 12 - 8 = -12$
$\displaystyle f(-1) = 2\cdot (-1)^{2} + 6\cdot (-1) - 8 = 2 - 6 - 8 = -12$
$\displaystyle f(2) = 2\cdot 2^{2} + 6\cdot 2 - 8 = 8 + 12 - 8 = 12$
Fleygboginn er samhverfur um $x = -1{,}5$, svo hver punktur á sér spegilmynd hinum megin við ásinn. Teiknum slétta sveigju í gegnum alla punktana.
Svar: Sjá mynd.
5. Leirdúfu er skotið af palli. Leirdúfan flýgur eftir ferlinum $$y = 6 + 7x - 0{,}5x^2$$ þar sem $x$ er fjarlægð frá skotstað og $y$ er hæð leirdúfunnar, hvort tveggja í metrum.
a. Úr hvaða hæð er leirdúfunni skotið?
Skotið er þar sem $x = 0$:$\displaystyle y = 6 + 7\cdot 0 - 0{,}5\cdot 0^{2} = 6$
Svar: $6$ m
b. Hver er mesta hæðin sem leirdúfan nær?
Hæsta staðan er á samhverfuásnum $x = -\dfrac{b}{2a}$, hér með $a = -0{,}5$ og $b = 7$:$\displaystyle x = \dfrac{-7}{2\cdot (-0{,}5)} = \dfrac{-7}{-1} = 7$
Hæðin þar:$\displaystyle y = 6 + 7\cdot 7 - 0{,}5\cdot 7^{2} = 6 + 49 - 24{,}5 = 30{,}5$
$a = -0{,}5 < 0$, svo fleygboginn opnast niður og þetta er hæsti punkturinn.
Svar: $30{,}5$ m
c. Hve langt frá pallinum er leirdúfan þegar hún lendir á jörðinni?
Leirdúfan lendir þegar $y = 0$:$\displaystyle 6 + 7x - 0{,}5x^{2} = 0$
Margföldum báðar hliðar með $-2$:$\displaystyle x^{2} - 14x - 12 = 0$
$\displaystyle a = 1,\quad b = -14,\quad c = -12$
Aðgreinirinn:$\displaystyle d = (-14)^{2} - 4\cdot 1\cdot (-12) = 196 + 48 = 244$
Lausnarformúlan gefur$\displaystyle x = \dfrac{14 \pm \sqrt{244}}{2}$
Einföldum rótina:$\displaystyle \sqrt{244} = \sqrt{4\cdot 61} = 2\sqrt{61}$
Styttum með $2$:$\displaystyle x = 7 \pm \sqrt{61}$
$x = 7 - \sqrt{61} \approx -0{,}81$ er neikvæð og kemur ekki til greina sem fjarlægð. Því er $x = 7 + \sqrt{61} \approx 14{,}81$.
Svar: $x \approx 14{,}81$ m
6. Fyrir hvaða gildi á $c$ hefur jafnan $x^2 + 13x + c = 0$ tvær rauntölulausnir?
Hér er $a = 1$, $b = 13$ og fastaliðurinn $c$. Aðgreinirinn $d = b^2 - 4ac$ er$\displaystyle d = 13^{2} - 4c = 169 - 4c$
Jafnan hefur tvær rauntölulausnir þegar $d > 0$:$\displaystyle 169 - 4c > 0$
Leggjum $4c$ við báðar hliðar:$\displaystyle 169 > 4c$
Deilum með $4$:$\displaystyle c < 42{,}25$
Svar: $c < 42{,}25$
7. Gefið er að $f(x) = x^2 + bx + c$ hefur núllstöðvarnar $x = 3$ og $x = -8$. Hver er margliðan?
Fyrst $x = 3$ og $x = -8$ eru núllstöðvar, eru $x - 3$ og $x + 8$ þættir í $f(x)$, og stuðull $x^2$ er $1$:
$\displaystyle f(x) = (x - 3)(x + 8)$
Margföldum upp úr svigunum:$\displaystyle (x - 3)(x + 8) = x^{2} + 8x - 3x - 24 = x^{2} + 5x - 24$
Þá er $b = 5$ og $c = -24$.
Svar: $f(x) = x^2 + 5x - 24$
8. Finndu afganginn (leifina) þegar $(x + 3)$ er deilt upp í margliðuna $3x^3 - x^2 + 2x + 6$.
Leifareglan: leifin þegar $f(x)$ er deilt með $x - a$ er $f(a)$. Deilirinn er $x + 3 = x - (-3)$, svo $a = -3$.
$\displaystyle f(-3) = 3\cdot (-3)^{3} - (-3)^{2} + 2\cdot (-3) + 6 = -81 - 9 - 6 + 6 = -90$
Svar: $-90$
9. Leystu ójöfnuna $(x + 5)(x - 1)(x - 3) \geq 0$. Svaraðu bæði með lausnargrafi og biltáknum.
Núllstöðvar þáttanna:$\displaystyle x + 5 = 0 \quad\text{eða}\quad x - 1 = 0 \quad\text{eða}\quad x - 3 = 0$
þ.e.$\displaystyle x = -5 \quad\text{eða}\quad x = 1 \quad\text{eða}\quad x = 3$

$x + 5$−0+++++

$\geq 0$: þar sem neðsta línan sýnir $+$ eða $0$:$\displaystyle -5 \leq x \leq 1 \quad\text{eða}\quad x \geq 3$
Svar: $\mathopen{[}{-5},\ {1}\mathclose{]}$ eða $\mathopen{[}{3},\ \infty\mathclose{[}$
10. Leystu ójöfnuna $(x - 2)^2(x - 5)^3(x + 2) \leq 0$. Svaraðu bæði með lausnargrafi og biltáknum.
Núllstöðvar þáttanna:$\displaystyle (x - 2)^{2} = 0 \quad\text{eða}\quad (x - 5)^{3} = 0 \quad\text{eða}\quad x + 2 = 0$
þ.e.$\displaystyle x = -2 \quad\text{eða}\quad x = 2 \quad\text{eða}\quad x = 5$
Formerkjamynd:
$x$$-2$$2$$5$
$(x - 2)^{2}$+++0+++

Þátturinn $(x - 2)^2$ er aldrei neikvæður (slétt veldi), svo formerkið skiptir ekki um við $x = 2$; $(x - 5)^3$ hefur sama formerki og $x - 5$.
$\leq 0$: þar sem neðsta línan sýnir $-$ eða $0$:$\displaystyle -2 \leq x \leq 5$
Svar: $\mathopen{[}{-2},\ {5}\mathclose{]}$
11. Leystu jöfnuna $x^3 - 7x^2 + 4x + 12 = 0$.
Köllum vinstri hliðina $f(x)$. Heiltölulausnir eru deilar fastaliðarins $12$: $\pm1, \pm2, \pm3, \pm4, \pm6, \pm12$. Prófum:
$\displaystyle f(1) = 1^{3} - 7\cdot 1^{2} + 4\cdot 1 + 12 = 10$$\neq 0$
$\displaystyle f(-1) = (-1)^{3} - 7\cdot (-1)^{2} + 4\cdot (-1) + 12 = 0$svo $x + 1$ er þáttur.
Deilum með $x + 1$ (stuðlaaðferð, $a = -1$):
$-1$$1$$-7$$4$$12$
$-1$$8$$-12$
$1$$-8$$12$$0$
Kvóti $x^2 - 8x + 12$, leif $0$.
svo að$\displaystyle x^{3} - 7x^{2} + 4x + 12 = (x + 1)(x^{2} - 8x + 12)$
Þáttum annars stigs þáttinn: tölurnar $-2$ og $-6$ hafa margfeldið $12$ og summuna $-8$:$\displaystyle x^{2} - 8x + 12 = (x - 2)(x - 6)$
Jafnan er því$\displaystyle (x + 1)(x - 2)(x - 6) = 0$
Núllþáttareglan gefur$\displaystyle x = -1 \quad\text{eða}\quad x = 2 \quad\text{eða}\quad x = 6$
Svar: $x = -1$ eða $x = 2$ eða $x = 6$
12. Gefin er margliðan $f(x) = x^3 - 5x^2 + 2x + 8$.
a. Finndu leifina (afganginn) ef deilt er í margliðuna með $x - 2$.
Deilum með $x - 2$ (stuðlaaðferð, $a = 2$):
$2$$1$$-5$$2$$8$
$2$$-6$$-8$
$1$$-3$$-4$$0$
Kvóti $x^2 - 3x - 4$, leif $0$.
Til staðfestingar, með leifareglunni:$\displaystyle f(2) = 2^{3} - 5\cdot 2^{2} + 2\cdot 2 + 8 = 8 - 20 + 4 + 8 = 0$
Svar: $0$
b. Fullþáttaðu margliðuna.
Leifin í a-lið er $0$, svo $x - 2$ er þáttur og kvótinn er hinn þátturinn:$\displaystyle x^{3} - 5x^{2} + 2x + 8 = (x - 2)(x^{2} - 3x - 4)$
Tölurnar $1$ og $-4$ hafa margfeldið $-4$ og summuna $-3$:$\displaystyle x^{2} - 3x - 4 = (x + 1)(x - 4)$
svo að$\displaystyle x^{3} - 5x^{2} + 2x + 8 = (x - 2)(x + 1)(x - 4)$
Svar: $f(x) = (x - 2)(x + 1)(x - 4)$
c. Leystu jöfnuna $x^3 - 5x^2 + 2x + 8 = 0$ (notaðu þáttunina í b-lið).
Með þáttuninni úr b-lið verður jafnan$\displaystyle (x - 2)(x + 1)(x - 4) = 0$
Núllþáttareglan gefur$\displaystyle x - 2 = 0 \quad\text{eða}\quad x + 1 = 0 \quad\text{eða}\quad x - 4 = 0$
svo að$\displaystyle x = -1 \quad\text{eða}\quad x = 2 \quad\text{eða}\quad x = 4$
Svar: $x = -1$ eða $x = 2$ eða $x = 4$
d. Leystu ójöfnuna $x^3 - 5x^2 + 2x + 8 > 0$ (notaðu núllstöðvarnar úr c-lið) og svaraðu í biltáknum.
Núllstöðvar þáttanna:$\displaystyle x - 2 = 0 \quad\text{eða}\quad x + 1 = 0 \quad\text{eða}\quad x - 4 = 0$
þ.e.$\displaystyle x = -1 \quad\text{eða}\quad x = 2 \quad\text{eða}\quad x = 4$

$x - 2$−−−0+++
$x + 1$−0+++++
$x - 4$−−−−−0+
$f(x)$−0+0−0+
$> 0$: þar sem neðsta línan sýnir $+$:$\displaystyle -1 < x < 2 \quad\text{eða}\quad x > 4$
