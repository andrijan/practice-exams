Formúlur

Núllþáttareglan: ef $a \cdot b = 0$ þá er $a = 0$ eða $b = 0$.
Lausnarformúlan: $ax^2 + bx + c = 0$ hefur lausnirnar $x = \dfrac{-b \pm \sqrt{d}}{2a}$ þar sem $d = b^2 - 4ac$. Ef $d > 0$ eru lausnirnar tvær, ef $d = 0$ ein og ef $d < 0$ engin.
Fleygboginn $y = ax^2 + bx + c$: samhverfuás $x = -\dfrac{b}{2a}$; opnast upp ef $a > 0$, niður ef $a < 0$.
Leifareglan: leifin þegar $f(x)$ er deilt með $x - a$ er $f(a)$.
Þáttunarreglan: ef $f(a) = 0$ þá er $x - a$ þáttur í $f(x)$.
Biltákn: $[a,\ b]$ tekur endapunktana með, $]a,\ b[$ ekki; $[a,\ \infty[$ er allt frá $a$ og upp úr.

Dæmi

1. Leystu jöfnurnar nákvæmt og strikaðu undir lokasvarið.
a. $(x - 2)(5 - x) = 0$
$\displaystyle (x - 2)(5 - x) = 0$
Núllþáttareglan gefur$\displaystyle x - 2 = 0 \quad\text{eða}\quad 5 - x = 0$
svo að$\displaystyle x = 2 \quad\text{eða}\quad x = 5$
Svar: $x = 2$ eða $x = 5$
b. $2x^2 + 4x + 3 = 0$
Jafnan er á staðlaða forminu $ax^2 + bx + c = 0$ með$\displaystyle 2x^{2} + 4x + 3 = 0$
$\displaystyle a = 2,\quad b = 4,\quad c = 3$
Aðgreinirinn:$\displaystyle d = 4^{2} - 4\cdot 2\cdot 3 = 16 - 24 = -8$
$d = -8 < 0$: það er engin rauntala sem hefur neikvæðan ferning, svo jafnan hefur enga lausn.
Svar: Engin lausn (í mengi rauntalna).
c. $x^2 = -4x$
$\displaystyle x^{2} = -4x$
Flytjum $-4x$ yfir á vinstri hlið (deilum ekki með $x$, þá týnist lausnin $x = 0$):$\displaystyle x^{2} + 4x = 0$
Tökum $x$ út fyrir sviga:$\displaystyle x^{2} + 4x = x(x + 4)$
Núllþáttareglan gefur$\displaystyle x = 0 \quad\text{eða}\quad x + 4 = 0$
svo að$\displaystyle x = 0 \quad\text{eða}\quad x = -4$
Svar: $x = 0$ eða $x = -4$
d. $\sqrt{x + 7} = x + 1$
$\displaystyle \sqrt{x + 7} = x + 1$
Hefjum báðar hliðar í annað veldi (þetta getur búið til falskar lausnir):$\displaystyle x + 7 = (x + 1)^{2}$
Margföldum upp úr sviganum:$\displaystyle (x + 1)^{2} = x^{2} + 2x + 1$
svo að$\displaystyle x + 7 = x^{2} + 2x + 1$
Flytjum allt yfir á eina hlið:$\displaystyle x^{2} + x - 6 = 0$
Þáttum:$\displaystyle x^{2} + x - 6 = (x - 2)(x + 3)$
Núllþáttareglan gefur$\displaystyle x = 2 \quad\text{eða}\quad x = -3$
Prófun, $x = 2$:$\displaystyle \text{vinstri hlið: } \sqrt{2 + 7} = 3, \quad \text{hægri hlið: } 2 + 1 = 3, \quad 3 = 3$✓ lausnin stenst.
Prófun, $x = -3$:$\displaystyle \text{vinstri hlið: } \sqrt{-3 + 7} = 2, \quad \text{hægri hlið: } -3 + 1 = -2, \quad 2 \neq -2$✗ fölsk lausn — höfnum henni.
Svar: $x = 2$ ($x = -3$ er fölsk lausn)
e. $x^4 + x^2 - 20 = 0$
Setjum $u = x^2$. Þá er $x^4 = u^2$ og jafnan verður$\displaystyle u^{2} + u - 20 = 0$
Tölurnar $-4$ og $5$ hafa margfeldið $-20$ og summuna $1$:$\displaystyle u^{2} + u - 20 = (u - 4)(u + 5)$
Núllþáttareglan gefur$\displaystyle u = 4 \quad\text{eða}\quad u = -5$
$u = x^2$ getur ekki verið neikvætt, svo $u = -5$ gefur enga lausn.
Skiptum $u$ út fyrir $x^2$:$\displaystyle x^{2} = 4$
Drögum ferningsrót af báðum hliðum:$\displaystyle x = \pm \sqrt{4} = \pm 2$
Svar: $x = \pm 2$
f. $3x^2 + 5 = 152$
$\displaystyle 3x^{2} + 5 = 152$
Drögum $5$ frá báðum hliðum:$\displaystyle 3x^{2} = 147$
Deilum með $3$:$\displaystyle x^{2} = \dfrac{147}{3} = 49$
Drögum ferningsrót af báðum hliðum:$\displaystyle x = \pm \sqrt{49} = \pm 7$
Svar: $x = \pm 7$
2. Notaðu aðferðina „að fylla í ferninginn“ til að leysa jöfnuna $x^2 - 8x - 5 = 0$.
$\displaystyle x^{2} - 8x - 5 = 0$
Flytjum fastaliðinn yfir á hægri hlið:$\displaystyle x^{2} - 8x = 5$
Helmingurinn af stuðli $x$ er $-4$. Bætum $(-4)^2 = 16$ við báðar hliðar:$\displaystyle x^{2} - 8x + 16 = 5 + 16$
Vinstri hliðin er fullkominn ferningur, $(x - 4)^2$:$\displaystyle (x - 4)^{2} = 21$
Drögum ferningsrót af báðum hliðum:$\displaystyle x - 4 = \pm \sqrt{21}$
Leggjum $4$ við báðar hliðar:$\displaystyle x = 4 \pm \sqrt{21}$
Svar: $x = 4 \pm \sqrt{21}$
3. Deildu með margliðudeilingu.
a. $(3x^3 - 2x^2 + 4) : (x - 2)$
Deilum fremsta lið með fremsta lið deilisins:$\displaystyle \dfrac{3x^{3}}{x} = 3x^{2}$
Margföldum deilinn með því:$\displaystyle 3x^{2}(x - 2) = 3x^{3} - 6x^{2}$
Drögum frá:$\displaystyle \left(3x^{3} - 2x^{2} + 4\right) - (3x^{3} - 6x^{2}) = 4x^{2} + 4$
Deilum fremsta lið með fremsta lið deilisins:$\displaystyle \dfrac{4x^{2}}{x} = 4x$
Margföldum deilinn með því:$\displaystyle 4x(x - 2) = 4x^{2} - 8x$
Drögum frá:$\displaystyle \left(4x^{2} + 4\right) - (4x^{2} - 8x) = 8x + 4$
Deilum fremsta lið með fremsta lið deilisins:$\displaystyle \dfrac{8x}{x} = 8$
Margföldum deilinn með því:$\displaystyle 8(x - 2) = 8x - 16$
Drögum frá:$\displaystyle \left(8x + 4\right) - (8x - 16) = 20$
Leifin $20$ er af lægra stigi en deilirinn, svo$\displaystyle \dfrac{3x^{3} - 2x^{2} + 4}{x - 2} = 3x^{2} + 4x + 8 + \dfrac{20}{x - 2}$
Svar: $3x^2 + 4x + 8 + \dfrac{20}{x - 2}$
b. $(3x^3 - 14x^2 + 17x - 6) : (x - 3)$
Deilum fremsta lið með fremsta lið deilisins:$\displaystyle \dfrac{3x^{3}}{x} = 3x^{2}$
Margföldum deilinn með því:$\displaystyle 3x^{2}(x - 3) = 3x^{3} - 9x^{2}$
Drögum frá:$\displaystyle \left(3x^{3} - 14x^{2} + 17x - 6\right) - (3x^{3} - 9x^{2}) = -5x^{2} + 17x - 6$
Deilum fremsta lið með fremsta lið deilisins:$\displaystyle \dfrac{-5x^{2}}{x} = -5x$
Margföldum deilinn með því:$\displaystyle -5x(x - 3) = -5x^{2} + 15x$
Drögum frá:$\displaystyle \left(-5x^{2} + 17x - 6\right) - (-5x^{2} + 15x) = 2x - 6$
Deilum fremsta lið með fremsta lið deilisins:$\displaystyle \dfrac{2x}{x} = 2$
Margföldum deilinn með því:$\displaystyle 2(x - 3) = 2x - 6$
Drögum frá:$\displaystyle \left(2x - 6\right) - (2x - 6) = 0$
Leifin $0$ er af lægra stigi en deilirinn, svo$\displaystyle \dfrac{3x^{3} - 14x^{2} + 17x - 6}{x - 3} = 3x^{2} - 5x + 2$
Svar: $3x^2 - 5x + 2$
4. Gefinn er fleygboginn $f(x) = 2x^2 + 2x - 4$.
a. Finndu jöfnu samhverfuássins (sýndu útreikninga).
Samhverfuásinn er $x = -\dfrac{b}{2a}$ með $a = 2$ og $b = 2$:$\displaystyle x = \dfrac{-2}{2\cdot 2} = \dfrac{-2}{4} = -\tfrac{1}{2}$
Svar: $x = -0{,}5$
b. Finndu topppunktinn (sýndu útreikninga).
Topppunkturinn er á samhverfuásnum. Setjum $x = -0{,}5$ inn:$\displaystyle y = 2\cdot (-\tfrac{1}{2})^{2} + 2\cdot (-\tfrac{1}{2}) - 4 = \tfrac{1}{2} - 1 - 4 = -\tfrac{9}{2}$
$a = 2 > 0$, svo fleygboginn opnast upp og topppunkturinn er lægsti punkturinn.
Svar: $(-0{,}5;\ -4{,}5)$
c. Finndu skurðpunktana við $x$-ás (sýndu útreikninga).
Á $x$-ás er $y = 0$:$\displaystyle 2x^{2} + 2x - 4 = 0$
Tökum $2$ út fyrir sviga:$\displaystyle 2x^{2} + 2x - 4 = 2(x^{2} + x - 2)$
Tölurnar $-1$ og $2$ hafa margfeldið $-2$ og summuna $1$:$\displaystyle x^{2} + x - 2 = (x - 1)(x + 2)$
svo jafnan er$\displaystyle 2(x - 1)(x + 2) = 0$
Núllþáttareglan gefur$\displaystyle x - 1 = 0 \quad\text{eða}\quad x + 2 = 0$
svo að$\displaystyle x = 1 \quad\text{eða}\quad x = -2$
Svar: $(-2, 0)$ og $(1, 0)$
d. Finndu skurðpunktinn við $y$-ás.
Á $y$-ás er $x = 0$:$\displaystyle y = 2\cdot 0^{2} + 2\cdot 0 - 4 = -4$
Svar: $(0, -4)$
e. Teiknaðu fleygbogann eins nákvæmlega og þú getur (finndu aukapunkta).
Merkjum skurðpunktana og topppunktinn úr a–d lið. Reiknum nokkra aukapunkta:
$\displaystyle f(-3) = 2\cdot (-3)^{2} + 2\cdot (-3) - 4 = 18 - 6 - 4 = 8$
$\displaystyle f(-1) = 2\cdot (-1)^{2} + 2\cdot (-1) - 4 = 2 - 2 - 4 = -4$
$\displaystyle f(2) = 2\cdot 2^{2} + 2\cdot 2 - 4 = 8 + 4 - 4 = 8$
Fleygboginn er samhverfur um $x = -0{,}5$, svo hver punktur á sér spegilmynd hinum megin við ásinn. Teiknum slétta sveigju í gegnum alla punktana.
Svar: Sjá mynd.
5. Leirdúfu er skotið af palli. Leirdúfan flýgur eftir ferlinum $$y = 3 + 8x - 0{,}5x^2$$ þar sem $x$ er fjarlægð frá skotstað og $y$ er hæð leirdúfunnar, hvort tveggja í metrum.
a. Úr hvaða hæð er leirdúfunni skotið?
Skotið er þar sem $x = 0$:$\displaystyle y = 3 + 8\cdot 0 - 0{,}5\cdot 0^{2} = 3$
Svar: $3$ m
b. Hver er mesta hæðin sem leirdúfan nær?
Hæsta staðan er á samhverfuásnum $x = -\dfrac{b}{2a}$, hér með $a = -0{,}5$ og $b = 8$:$\displaystyle x = \dfrac{-8}{2\cdot (-0{,}5)} = \dfrac{-8}{-1} = 8$
Hæðin þar:$\displaystyle y = 3 + 8\cdot 8 - 0{,}5\cdot 8^{2} = 3 + 64 - 32 = 35$
$a = -0{,}5 < 0$, svo fleygboginn opnast niður og þetta er hæsti punkturinn.
Svar: $35$ m
c. Hve langt frá pallinum er leirdúfan þegar hún lendir á jörðinni?
Leirdúfan lendir þegar $y = 0$:$\displaystyle 3 + 8x - 0{,}5x^{2} = 0$
Margföldum báðar hliðar með $-2$:$\displaystyle x^{2} - 16x - 6 = 0$
$\displaystyle a = 1,\quad b = -16,\quad c = -6$
Aðgreinirinn:$\displaystyle d = (-16)^{2} - 4\cdot 1\cdot (-6) = 256 + 24 = 280$
Lausnarformúlan gefur$\displaystyle x = \dfrac{16 \pm \sqrt{280}}{2}$
Einföldum rótina:$\displaystyle \sqrt{280} = \sqrt{4\cdot 70} = 2\sqrt{70}$
Styttum með $2$:$\displaystyle x = 8 \pm \sqrt{70}$
$x = 8 - \sqrt{70} \approx -0{,}37$ er neikvæð og kemur ekki til greina sem fjarlægð. Því er $x = 8 + \sqrt{70} \approx 16{,}37$.
Svar: $x \approx 16{,}37$ m
6. Fyrir hvaða gildi á $c$ hefur jafnan $x^2 - 7x + c = 0$ tvær rauntölulausnir?
Hér er $a = 1$, $b = -7$ og fastaliðurinn $c$. Aðgreinirinn $d = b^2 - 4ac$ er$\displaystyle d = (-7)^{2} - 4c = 49 - 4c$
Jafnan hefur tvær rauntölulausnir þegar $d > 0$:$\displaystyle 49 - 4c > 0$
Leggjum $4c$ við báðar hliðar:$\displaystyle 49 > 4c$
Deilum með $4$:$\displaystyle c < 12{,}25$
Svar: $c < 12{,}25$
7. Gefið er að $f(x) = x^2 + bx + c$ hefur núllstöðvarnar $x = 4$ og $x = -7$. Hver er margliðan?
Fyrst $x = 4$ og $x = -7$ eru núllstöðvar, eru $x - 4$ og $x + 7$ þættir í $f(x)$, og stuðull $x^2$ er $1$:
$\displaystyle f(x) = (x - 4)(x + 7)$
Margföldum upp úr svigunum:$\displaystyle (x - 4)(x + 7) = x^{2} + 7x - 4x - 28 = x^{2} + 3x - 28$
Þá er $b = 3$ og $c = -28$.
Svar: $f(x) = x^2 + 3x - 28$
8. Finndu afganginn (leifina) þegar $(x + 4)$ er deilt upp í margliðuna $2x^3 + 3x^2 - 5x + 6$.
Leifareglan: leifin þegar $f(x)$ er deilt með $x - a$ er $f(a)$. Deilirinn er $x + 4 = x - (-4)$, svo $a = -4$.
$\displaystyle f(-4) = 2\cdot (-4)^{3} + 3\cdot (-4)^{2} - 5\cdot (-4) + 6 = -128 + 48 + 20 + 6 = -54$
Svar: $-54$
9. Leystu ójöfnuna $(x + 4)(x - 3)(x + 2) \geq 0$. Svaraðu bæði með lausnargrafi og biltáknum.
Núllstöðvar þáttanna:$\displaystyle x + 4 = 0 \quad\text{eða}\quad x - 3 = 0 \quad\text{eða}\quad x + 2 = 0$
þ.e.$\displaystyle x = -4 \quad\text{eða}\quad x = -2 \quad\text{eða}\quad x = 3$
Formerkjamynd:
$x$$-4$$-2$$3$
$x + 4$−0+++++
$x - 3$−−−−−0+
$x + 2$−−−0+++
$f(x)$−0+0−0+
$\geq 0$: þar sem neðsta línan sýnir $+$ eða $0$:$\displaystyle -4 \leq x \leq -2 \quad\text{eða}\quad x \geq 3$
Svar: $\mathopen{[}{-4},\ {-2}\mathclose{]}$ eða $\mathopen{[}{3},\ \infty\mathclose{[}$
10. Leystu ójöfnuna $(x + 1)^2(x - 4)^3(x + 3) \leq 0$. Svaraðu bæði með lausnargrafi og biltáknum.
Núllstöðvar þáttanna:$\displaystyle (x + 1)^{2} = 0 \quad\text{eða}\quad (x - 4)^{3} = 0 \quad\text{eða}\quad x + 3 = 0$
þ.e.$\displaystyle x = -3 \quad\text{eða}\quad x = -1 \quad\text{eða}\quad x = 4$
Formerkjamynd:
$x$$-3$$-1$$4$
$(x + 1)^{2}$+++0+++
$(x - 4)^{3}$−−−−−0+
$x + 3$−0+++++
$f(x)$+0−0−0+
Þátturinn $(x + 1)^2$ er aldrei neikvæður (slétt veldi), svo formerkið skiptir ekki um við $x = -1$; $(x - 4)^3$ hefur sama formerki og $x - 4$.
$\leq 0$: þar sem neðsta línan sýnir $-$ eða $0$:$\displaystyle -3 \leq x \leq 4$
Svar: $\mathopen{[}{-3},\ {4}\mathclose{]}$
11. Leystu jöfnuna $x^3 - 4x^2 - 7x + 10 = 0$.
Köllum vinstri hliðina $f(x)$. Heiltölulausnir eru deilar fastaliðarins $10$: $\pm1, \pm2, \pm5, \pm10$. Prófum:
$\displaystyle f(1) = 1^{3} - 4\cdot 1^{2} - 7\cdot 1 + 10 = 0$svo $x - 1$ er þáttur.
Deilum með $x - 1$ (stuðlaaðferð, $a = 1$):
$1$$1$$-4$$-7$$10$
$1$$-3$$-10$
$1$$-3$$-10$$0$
Kvóti $x^2 - 3x - 10$, leif $0$.
svo að$\displaystyle x^{3} - 4x^{2} - 7x + 10 = (x - 1)(x^{2} - 3x - 10)$
Þáttum annars stigs þáttinn: tölurnar $-5$ og $2$ hafa margfeldið $-10$ og summuna $-3$:$\displaystyle x^{2} - 3x - 10 = (x - 5)(x + 2)$
Jafnan er því$\displaystyle (x - 1)(x - 5)(x + 2) = 0$
Núllþáttareglan gefur$\displaystyle x = 1 \quad\text{eða}\quad x = 5 \quad\text{eða}\quad x = -2$
Svar: $x = -2$ eða $x = 1$ eða $x = 5$
12. Gefin er margliðan $f(x) = x^3 - 2x^2 - 5x + 6$.
a. Finndu leifina (afganginn) ef deilt er í margliðuna með $x + 2$.
Deilum með $x + 2$ (stuðlaaðferð, $a = -2$):
$-2$$1$$-2$$-5$$6$
$-2$$8$$-6$
$1$$-4$$3$$0$
Kvóti $x^2 - 4x + 3$, leif $0$.
Til staðfestingar, með leifareglunni:$\displaystyle f(-2) = (-2)^{3} - 2\cdot (-2)^{2} - 5\cdot (-2) + 6 = -8 - 8 + 10 + 6 = 0$
Svar: $0$
b. Fullþáttaðu margliðuna.
Leifin í a-lið er $0$, svo $x + 2$ er þáttur og kvótinn er hinn þátturinn:$\displaystyle x^{3} - 2x^{2} - 5x + 6 = (x + 2)(x^{2} - 4x + 3)$
Tölurnar $-1$ og $-3$ hafa margfeldið $3$ og summuna $-4$:$\displaystyle x^{2} - 4x + 3 = (x - 1)(x - 3)$
svo að$\displaystyle x^{3} - 2x^{2} - 5x + 6 = (x + 2)(x - 1)(x - 3)$
Svar: $f(x) = (x + 2)(x - 1)(x - 3)$
c. Leystu jöfnuna $x^3 - 2x^2 - 5x + 6 = 0$ (notaðu þáttunina í b-lið).
Með þáttuninni úr b-lið verður jafnan$\displaystyle (x + 2)(x - 1)(x - 3) = 0$
Núllþáttareglan gefur$\displaystyle x + 2 = 0 \quad\text{eða}\quad x - 1 = 0 \quad\text{eða}\quad x - 3 = 0$
svo að$\displaystyle x = -2 \quad\text{eða}\quad x = 1 \quad\text{eða}\quad x = 3$
Svar: $x = -2$ eða $x = 1$ eða $x = 3$
d. Leystu ójöfnuna $x^3 - 2x^2 - 5x + 6 > 0$ (notaðu núllstöðvarnar úr c-lið) og svaraðu í biltáknum.
Núllstöðvar þáttanna:$\displaystyle x + 2 = 0 \quad\text{eða}\quad x - 1 = 0 \quad\text{eða}\quad x - 3 = 0$
þ.e.$\displaystyle x = -2 \quad\text{eða}\quad x = 1 \quad\text{eða}\quad x = 3$
Formerkjamynd:
$x$$-2$$1$$3$
$x + 2$−0+++++
$x - 1$−−−0+++
$x - 3$−−−−−0+
$f(x)$−0+0−0+
$> 0$: þar sem neðsta línan sýnir $+$:$\displaystyle -2 < x < 1 \quad\text{eða}\quad x > 3$
Svar: $\mathopen{]}{-2},\ {1}\mathclose{[}$ eða $\mathopen{]}{3},\ \infty\mathclose{[}$
