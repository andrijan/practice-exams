Formúlur

Núllþáttareglan: ef $a \cdot b = 0$ þá er $a = 0$ eða $b = 0$.
Lausnarformúlan: $ax^2 + bx + c = 0$ hefur lausnirnar $x = \dfrac{-b \pm \sqrt{d}}{2a}$ þar sem $d = b^2 - 4ac$. Ef $d > 0$ eru lausnirnar tvær, ef $d = 0$ ein og ef $d < 0$ engin.
Fleygboginn $y = ax^2 + bx + c$: samhverfuás $x = -\dfrac{b}{2a}$; opnast upp ef $a > 0$, niður ef $a < 0$.
Leifareglan: leifin þegar $f(x)$ er deilt með $x - a$ er $f(a)$.
Þáttunarreglan: ef $f(a) = 0$ þá er $x - a$ þáttur í $f(x)$.
Biltákn: $[a,\ b]$ tekur endapunktana með, $]a,\ b[$ ekki; $[a,\ \infty[$ er allt frá $a$ og upp úr.

Dæmi

1. Leystu jöfnurnar nákvæmt og strikaðu undir lokasvarið.
a. $(x - 3)(6 - x) = 0$
$\displaystyle (x - 3)(6 - x) = 0$
Núllþáttareglan gefur$\displaystyle x - 3 = 0 \quad\text{eða}\quad 6 - x = 0$
svo að$\displaystyle x = 3 \quad\text{eða}\quad x = 6$
Svar: $x = 3$ eða $x = 6$
b. $2x^2 + 2x + 5 = 0$
Jafnan er á staðlaða forminu $ax^2 + bx + c = 0$ með$\displaystyle 2x^{2} + 2x + 5 = 0$
$\displaystyle a = 2,\quad b = 2,\quad c = 5$
Aðgreinirinn:$\displaystyle d = 2^{2} - 4\cdot 2\cdot 5 = 4 - 40 = -36$
$d = -36 < 0$: það er engin rauntala sem hefur neikvæðan ferning, svo jafnan hefur enga lausn.
Svar: Engin lausn (í mengi rauntalna).
c. $x^2 = -5x$
$\displaystyle x^{2} = -5x$
Flytjum $-5x$ yfir á vinstri hlið (deilum ekki með $x$, þá týnist lausnin $x = 0$):$\displaystyle x^{2} + 5x = 0$
Tökum $x$ út fyrir sviga:$\displaystyle x^{2} + 5x = x(x + 5)$
Núllþáttareglan gefur$\displaystyle x = 0 \quad\text{eða}\quad x + 5 = 0$
svo að$\displaystyle x = 0 \quad\text{eða}\quad x = -5$
Svar: $x = 0$ eða $x = -5$
d. $\sqrt{x + 13} = x + 1$
$\displaystyle \sqrt{x + 13} = x + 1$
Hefjum báðar hliðar í annað veldi (þetta getur búið til falskar lausnir):$\displaystyle x + 13 = (x + 1)^{2}$
Margföldum upp úr sviganum:$\displaystyle (x + 1)^{2} = x^{2} + 2x + 1$
svo að$\displaystyle x + 13 = x^{2} + 2x + 1$
Flytjum allt yfir á eina hlið:$\displaystyle x^{2} + x - 12 = 0$
Þáttum:$\displaystyle x^{2} + x - 12 = (x - 3)(x + 4)$
Núllþáttareglan gefur$\displaystyle x = 3 \quad\text{eða}\quad x = -4$
Prófun, $x = 3$:$\displaystyle \text{vinstri hlið: } \sqrt{3 + 13} = 4, \quad \text{hægri hlið: } 3 + 1 = 4, \quad 4 = 4$✓ lausnin stenst.
Prófun, $x = -4$:$\displaystyle \text{vinstri hlið: } \sqrt{-4 + 13} = 3, \quad \text{hægri hlið: } -4 + 1 = -3, \quad 3 \neq -3$✗ fölsk lausn — höfnum henni.
Svar: $x = 3$ ($x = -4$ er fölsk lausn)
e. $x^4 - 35x^2 - 36 = 0$
Setjum $u = x^2$. Þá er $x^4 = u^2$ og jafnan verður$\displaystyle u^{2} - 35u - 36 = 0$
Tölurnar $-36$ og $1$ hafa margfeldið $-36$ og summuna $-35$:$\displaystyle u^{2} - 35u - 36 = (u - 36)(u + 1)$
Núllþáttareglan gefur$\displaystyle u = 36 \quad\text{eða}\quad u = -1$
$u = x^2$ getur ekki verið neikvætt, svo $u = -1$ gefur enga lausn.
Skiptum $u$ út fyrir $x^2$:$\displaystyle x^{2} = 36$
Drögum ferningsrót af báðum hliðum:$\displaystyle x = \pm \sqrt{36} = \pm 6$
Svar: $x = \pm 6$
f. $2x^2 + 3 = 75$
$\displaystyle 2x^{2} + 3 = 75$
Drögum $3$ frá báðum hliðum:$\displaystyle 2x^{2} = 72$
Deilum með $2$:$\displaystyle x^{2} = \dfrac{72}{2} = 36$
Drögum ferningsrót af báðum hliðum:$\displaystyle x = \pm \sqrt{36} = \pm 6$
Svar: $x = \pm 6$
2. Notaðu aðferðina „að fylla í ferninginn“ til að leysa jöfnuna $x^2 - 4x - 9 = 0$.
$\displaystyle x^{2} - 4x - 9 = 0$
Flytjum fastaliðinn yfir á hægri hlið:$\displaystyle x^{2} - 4x = 9$
Helmingurinn af stuðli $x$ er $-2$. Bætum $(-2)^2 = 4$ við báðar hliðar:$\displaystyle x^{2} - 4x + 4 = 9 + 4$
Vinstri hliðin er fullkominn ferningur, $(x - 2)^2$:$\displaystyle (x - 2)^{2} = 13$
Drögum ferningsrót af báðum hliðum:$\displaystyle x - 2 = \pm \sqrt{13}$
Leggjum $2$ við báðar hliðar:$\displaystyle x = 2 \pm \sqrt{13}$
Svar: $x = 2 \pm \sqrt{13}$
3. Deildu með margliðudeilingu.
a. $(3x^3 + x^2 - 4) : (x - 2)$
Deilum fremsta lið með fremsta lið deilisins:$\displaystyle \dfrac{3x^{3}}{x} = 3x^{2}$
Margföldum deilinn með því:$\displaystyle 3x^{2}(x - 2) = 3x^{3} - 6x^{2}$
Drögum frá:$\displaystyle \left(3x^{3} + x^{2} - 4\right) - (3x^{3} - 6x^{2}) = 7x^{2} - 4$
Deilum fremsta lið með fremsta lið deilisins:$\displaystyle \dfrac{7x^{2}}{x} = 7x$
Margföldum deilinn með því:$\displaystyle 7x(x - 2) = 7x^{2} - 14x$
Drögum frá:$\displaystyle \left(7x^{2} - 4\right) - (7x^{2} - 14x) = 14x - 4$
Deilum fremsta lið með fremsta lið deilisins:$\displaystyle \dfrac{14x}{x} = 14$
Margföldum deilinn með því:$\displaystyle 14(x - 2) = 14x - 28$
Drögum frá:$\displaystyle \left(14x - 4\right) - (14x - 28) = 24$
Leifin $24$ er af lægra stigi en deilirinn, svo$\displaystyle \dfrac{3x^{3} + x^{2} - 4}{x - 2} = 3x^{2} + 7x + 14 + \dfrac{24}{x - 2}$
Svar: $3x^2 + 7x + 14 + \dfrac{24}{x - 2}$
b. $(2x^3 - 9x^2 + 10x - 3) : (x - 3)$
Deilum fremsta lið með fremsta lið deilisins:$\displaystyle \dfrac{2x^{3}}{x} = 2x^{2}$
Margföldum deilinn með því:$\displaystyle 2x^{2}(x - 3) = 2x^{3} - 6x^{2}$
Drögum frá:$\displaystyle \left(2x^{3} - 9x^{2} + 10x - 3\right) - (2x^{3} - 6x^{2}) = -3x^{2} + 10x - 3$
Deilum fremsta lið með fremsta lið deilisins:$\displaystyle \dfrac{-3x^{2}}{x} = -3x$
Margföldum deilinn með því:$\displaystyle -3x(x - 3) = -3x^{2} + 9x$
Drögum frá:$\displaystyle \left(-3x^{2} + 10x - 3\right) - (-3x^{2} + 9x) = x - 3$
Deilum fremsta lið með fremsta lið deilisins:$\displaystyle \dfrac{x}{x} = 1$
Margföldum deilinn með því:$\displaystyle 1(x - 3) = x - 3$
Drögum frá:$\displaystyle \left(x - 3\right) - (x - 3) = 0$
Leifin $0$ er af lægra stigi en deilirinn, svo$\displaystyle \dfrac{2x^{3} - 9x^{2} + 10x - 3}{x - 3} = 2x^{2} - 3x + 1$
Svar: $2x^2 - 3x + 1$
4. Gefinn er fleygboginn $f(x) = 2x^2 - 6x - 20$.
a. Finndu jöfnu samhverfuássins (sýndu útreikninga).
Samhverfuásinn er $x = -\dfrac{b}{2a}$ með $a = 2$ og $b = -6$:$\displaystyle x = \dfrac{-(-6)}{2\cdot 2} = \dfrac{6}{4} = \tfrac{3}{2}$
Svar: $x = 1{,}5$
b. Finndu topppunktinn (sýndu útreikninga).
Topppunkturinn er á samhverfuásnum. Setjum $x = 1{,}5$ inn:$\displaystyle y = 2\cdot (\tfrac{3}{2})^{2} - 6\cdot \tfrac{3}{2} - 20 = \tfrac{9}{2} - 9 - 20 = -\tfrac{49}{2}$
$a = 2 > 0$, svo fleygboginn opnast upp og topppunkturinn er lægsti punkturinn.
Svar: $(1{,}5;\ -24{,}5)$
c. Finndu skurðpunktana við $x$-ás (sýndu útreikninga).
Á $x$-ás er $y = 0$:$\displaystyle 2x^{2} - 6x - 20 = 0$
Tökum $2$ út fyrir sviga:$\displaystyle 2x^{2} - 6x - 20 = 2(x^{2} - 3x - 10)$
Tölurnar $-5$ og $2$ hafa margfeldið $-10$ og summuna $-3$:$\displaystyle x^{2} - 3x - 10 = (x - 5)(x + 2)$
svo jafnan er$\displaystyle 2(x - 5)(x + 2) = 0$
Núllþáttareglan gefur$\displaystyle x - 5 = 0 \quad\text{eða}\quad x + 2 = 0$
svo að$\displaystyle x = 5 \quad\text{eða}\quad x = -2$
Svar: $(-2, 0)$ og $(5, 0)$
d. Finndu skurðpunktinn við $y$-ás.
Á $y$-ás er $x = 0$:$\displaystyle y = 2\cdot 0^{2} - 6\cdot 0 - 20 = -20$
Svar: $(0, -20)$
e. Teiknaðu fleygbogann eins nákvæmlega og þú getur (finndu aukapunkta).
Merkjum skurðpunktana og topppunktinn úr a–d lið. Reiknum nokkra aukapunkta:
$\displaystyle f(-3) = 2\cdot (-3)^{2} - 6\cdot (-3) - 20 = 18 + 18 - 20 = 16$
$\displaystyle f(1) = 2\cdot 1^{2} - 6\cdot 1 - 20 = 2 - 6 - 20 = -24$
$\displaystyle f(2) = 2\cdot 2^{2} - 6\cdot 2 - 20 = 8 - 12 - 20 = -24$
$\displaystyle f(6) = 2\cdot 6^{2} - 6\cdot 6 - 20 = 72 - 36 - 20 = 16$
Fleygboginn er samhverfur um $x = 1{,}5$, svo hver punktur á sér spegilmynd hinum megin við ásinn. Teiknum slétta sveigju í gegnum alla punktana.
Svar: Sjá mynd.
5. Leirdúfu er skotið af palli. Leirdúfan flýgur eftir ferlinum $$y = 5 + 6x - 0{,}5x^2$$ þar sem $x$ er fjarlægð frá skotstað og $y$ er hæð leirdúfunnar, hvort tveggja í metrum.
a. Úr hvaða hæð er leirdúfunni skotið?
Skotið er þar sem $x = 0$:$\displaystyle y = 5 + 6\cdot 0 - 0{,}5\cdot 0^{2} = 5$
Svar: $5$ m
b. Hver er mesta hæðin sem leirdúfan nær?
Hæsta staðan er á samhverfuásnum $x = -\dfrac{b}{2a}$, hér með $a = -0{,}5$ og $b = 6$:$\displaystyle x = \dfrac{-6}{2\cdot (-0{,}5)} = \dfrac{-6}{-1} = 6$
Hæðin þar:$\displaystyle y = 5 + 6\cdot 6 - 0{,}5\cdot 6^{2} = 5 + 36 - 18 = 23$
$a = -0{,}5 < 0$, svo fleygboginn opnast niður og þetta er hæsti punkturinn.
Svar: $23$ m
c. Hve langt frá pallinum er leirdúfan þegar hún lendir á jörðinni?
Leirdúfan lendir þegar $y = 0$:$\displaystyle 5 + 6x - 0{,}5x^{2} = 0$
Margföldum báðar hliðar með $-2$:$\displaystyle x^{2} - 12x - 10 = 0$
$\displaystyle a = 1,\quad b = -12,\quad c = -10$
Aðgreinirinn:$\displaystyle d = (-12)^{2} - 4\cdot 1\cdot (-10) = 144 + 40 = 184$
Lausnarformúlan gefur$\displaystyle x = \dfrac{12 \pm \sqrt{184}}{2}$
Einföldum rótina:$\displaystyle \sqrt{184} = \sqrt{4\cdot 46} = 2\sqrt{46}$
Styttum með $2$:$\displaystyle x = 6 \pm \sqrt{46}$
$x = 6 - \sqrt{46} \approx -0{,}78$ er neikvæð og kemur ekki til greina sem fjarlægð. Því er $x = 6 + \sqrt{46} \approx 12{,}78$.
Svar: $x \approx 12{,}78$ m
6. Fyrir hvaða gildi á $c$ hefur jafnan $x^2 - 11x + c = 0$ tvær rauntölulausnir?
Hér er $a = 1$, $b = -11$ og fastaliðurinn $c$. Aðgreinirinn $d = b^2 - 4ac$ er$\displaystyle d = (-11)^{2} - 4c = 121 - 4c$
Jafnan hefur tvær rauntölulausnir þegar $d > 0$:$\displaystyle 121 - 4c > 0$
Leggjum $4c$ við báðar hliðar:$\displaystyle 121 > 4c$
Deilum með $4$:$\displaystyle c < 30{,}25$
Svar: $c < 30{,}25$
7. Gefið er að $f(x) = x^2 + bx + c$ hefur núllstöðvarnar $x = 7$ og $x = -4$. Hver er margliðan?
Fyrst $x = 7$ og $x = -4$ eru núllstöðvar, eru $x - 7$ og $x + 4$ þættir í $f(x)$, og stuðull $x^2$ er $1$:
$\displaystyle f(x) = (x - 7)(x + 4)$
Margföldum upp úr svigunum:$\displaystyle (x - 7)(x + 4) = x^{2} + 4x - 7x - 28 = x^{2} - 3x - 28$
Þá er $b = -3$ og $c = -28$.
Svar: $f(x) = x^2 - 3x - 28$
8. Finndu afganginn (leifina) þegar $(x + 4)$ er deilt upp í margliðuna $2x^3 - 3x^2 + 4x - 5$.
Leifareglan: leifin þegar $f(x)$ er deilt með $x - a$ er $f(a)$. Deilirinn er $x + 4 = x - (-4)$, svo $a = -4$.
$\displaystyle f(-4) = 2\cdot (-4)^{3} - 3\cdot (-4)^{2} + 4\cdot (-4) - 5 = -128 - 48 - 16 - 5 = -197$
Svar: $-197$
9. Leystu ójöfnuna $(x + 3)(x - 4)(x + 1) \geq 0$. Svaraðu bæði með lausnargrafi og biltáknum.
Núllstöðvar þáttanna:$\displaystyle x + 3 = 0 \quad\text{eða}\quad x - 4 = 0 \quad\text{eða}\quad x + 1 = 0$
þ.e.$\displaystyle x = -3 \quad\text{eða}\quad x = -1 \quad\text{eða}\quad x = 4$

$x + 3$−0+++++

$x + 1$−−−0+++

$\geq 0$: þar sem neðsta línan sýnir $+$ eða $0$:$\displaystyle -3 \leq x \leq -1 \quad\text{eða}\quad x \geq 4$
Svar: $\mathopen{[}{-3},\ {-1}\mathclose{]}$ eða $\mathopen{[}{4},\ \infty\mathclose{[}$
10. Leystu ójöfnuna $(x + 1)^2(x - 2)^3(x + 4) \leq 0$. Svaraðu bæði með lausnargrafi og biltáknum.
Núllstöðvar þáttanna:$\displaystyle (x + 1)^{2} = 0 \quad\text{eða}\quad (x - 2)^{3} = 0 \quad\text{eða}\quad x + 4 = 0$
þ.e.$\displaystyle x = -4 \quad\text{eða}\quad x = -1 \quad\text{eða}\quad x = 2$
Formerkjamynd:
$x$$-4$$-1$$2$
$(x + 1)^{2}$+++0+++
$(x - 2)^{3}$−−−−−0+
$x + 4$−0+++++
$f(x)$+0−0−0+
Þátturinn $(x + 1)^2$ er aldrei neikvæður (slétt veldi), svo formerkið skiptir ekki um við $x = -1$; $(x - 2)^3$ hefur sama formerki og $x - 2$.
$\leq 0$: þar sem neðsta línan sýnir $-$ eða $0$:$\displaystyle -4 \leq x \leq 2$
Svar: $\mathopen{[}{-4},\ {2}\mathclose{]}$
11. Leystu jöfnuna $x^3 - 4x^2 - 11x + 30 = 0$.
Köllum vinstri hliðina $f(x)$. Heiltölulausnir eru deilar fastaliðarins $30$: $\pm1, \pm2, \pm3, \pm5, \pm6, \pm10, \pm15, \pm30$. Prófum:
$\displaystyle f(1) = 1^{3} - 4\cdot 1^{2} - 11\cdot 1 + 30 = 16$$\neq 0$
$\displaystyle f(-1) = (-1)^{3} - 4\cdot (-1)^{2} - 11\cdot (-1) + 30 = 36$$\neq 0$
$\displaystyle f(2) = 2^{3} - 4\cdot 2^{2} - 11\cdot 2 + 30 = 0$svo $x - 2$ er þáttur.
Deilum með $x - 2$ (stuðlaaðferð, $a = 2$):
$2$$1$$-4$$-11$$30$
$2$$-4$$-30$
$1$$-2$$-15$$0$
Kvóti $x^2 - 2x - 15$, leif $0$.
svo að$\displaystyle x^{3} - 4x^{2} - 11x + 30 = (x - 2)(x^{2} - 2x - 15)$
Þáttum annars stigs þáttinn: tölurnar $3$ og $-5$ hafa margfeldið $-15$ og summuna $-2$:$\displaystyle x^{2} - 2x - 15 = (x + 3)(x - 5)$
Jafnan er því$\displaystyle (x - 2)(x + 3)(x - 5) = 0$
Núllþáttareglan gefur$\displaystyle x = 2 \quad\text{eða}\quad x = -3 \quad\text{eða}\quad x = 5$
Svar: $x = -3$ eða $x = 2$ eða $x = 5$
12. Gefin er margliðan $f(x) = x^3 + x^2 - 10x + 8$.
a. Finndu leifina (afganginn) ef deilt er í margliðuna með $x + 4$.
Deilum með $x + 4$ (stuðlaaðferð, $a = -4$):
$-4$$1$$1$$-10$$8$
$-4$$12$$-8$
$1$$-3$$2$$0$
Kvóti $x^2 - 3x + 2$, leif $0$.
Til staðfestingar, með leifareglunni:$\displaystyle f(-4) = (-4)^{3} + (-4)^{2} - 10\cdot (-4) + 8 = -64 + 16 + 40 + 8 = 0$
Svar: $0$
b. Fullþáttaðu margliðuna.
Leifin í a-lið er $0$, svo $x + 4$ er þáttur og kvótinn er hinn þátturinn:$\displaystyle x^{3} + x^{2} - 10x + 8 = (x + 4)(x^{2} - 3x + 2)$
Tölurnar $-1$ og $-2$ hafa margfeldið $2$ og summuna $-3$:$\displaystyle x^{2} - 3x + 2 = (x - 1)(x - 2)$
svo að$\displaystyle x^{3} + x^{2} - 10x + 8 = (x + 4)(x - 1)(x - 2)$
Svar: $f(x) = (x + 4)(x - 1)(x - 2)$
c. Leystu jöfnuna $x^3 + x^2 - 10x + 8 = 0$ (notaðu þáttunina í b-lið).
Með þáttuninni úr b-lið verður jafnan$\displaystyle (x + 4)(x - 1)(x - 2) = 0$
Núllþáttareglan gefur$\displaystyle x + 4 = 0 \quad\text{eða}\quad x - 1 = 0 \quad\text{eða}\quad x - 2 = 0$
svo að$\displaystyle x = -4 \quad\text{eða}\quad x = 1 \quad\text{eða}\quad x = 2$
Svar: $x = -4$ eða $x = 1$ eða $x = 2$
d. Leystu ójöfnuna $x^3 + x^2 - 10x + 8 > 0$ (notaðu núllstöðvarnar úr c-lið) og svaraðu í biltáknum.
Núllstöðvar þáttanna:$\displaystyle x + 4 = 0 \quad\text{eða}\quad x - 1 = 0 \quad\text{eða}\quad x - 2 = 0$
þ.e.$\displaystyle x = -4 \quad\text{eða}\quad x = 1 \quad\text{eða}\quad x = 2$

$x$$-4$$1$$2$
$x + 4$−0+++++
$x - 1$−−−0+++
$x - 2$−−−−−0+
$f(x)$−0+0−0+
$> 0$: þar sem neðsta línan sýnir $+$:$\displaystyle -4 < x < 1 \quad\text{eða}\quad x > 2$
Svar: $\mathopen{]}{-4},\ {1}\mathclose{[}$ eða $\mathopen{]}{2},\ \infty\mathclose{[}$
