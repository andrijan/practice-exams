Formúlur

Núllþáttareglan: ef $a \cdot b = 0$ þá er $a = 0$ eða $b = 0$.
Lausnarformúlan: $ax^2 + bx + c = 0$ hefur lausnirnar $x = \dfrac{-b \pm \sqrt{d}}{2a}$ þar sem $d = b^2 - 4ac$. Ef $d > 0$ eru lausnirnar tvær, ef $d = 0$ ein og ef $d < 0$ engin.
Fleygboginn $y = ax^2 + bx + c$: samhverfuás $x = -\dfrac{b}{2a}$; opnast upp ef $a > 0$, niður ef $a < 0$.
Leifareglan: leifin þegar $f(x)$ er deilt með $x - a$ er $f(a)$.
Þáttunarreglan: ef $f(a) = 0$ þá er $x - a$ þáttur í $f(x)$.
Biltákn: $[a,\ b]$ tekur endapunktana með, $]a,\ b[$ ekki; $[a,\ \infty[$ er allt frá $a$ og upp úr.

Lausnir

  1. 1. Leystu jöfnurnar nákvæmt og strikaðu undir lokasvarið.
    a. $(x + 2)(1 - x) = 0$
    $\displaystyle (x + 2)(1 - x) = 0$
    Núllþáttareglan gefur$\displaystyle x + 2 = 0 \quad\text{eða}\quad 1 - x = 0$
    svo að$\displaystyle x = -2 \quad\text{eða}\quad x = 1$
    Svar: $x = -2$ eða $x = 1$
    b. $5x^2 - 5x + 5 = 0$
    Jafnan er á staðlaða forminu $ax^2 + bx + c = 0$ með$\displaystyle 5x^{2} - 5x + 5 = 0$
    $\displaystyle a = 5,\quad b = -5,\quad c = 5$
    Aðgreinirinn:$\displaystyle d = (-5)^{2} - 4\cdot 5\cdot 5 = 25 - 100 = -75$
    $d = -75 < 0$: það er engin rauntala sem hefur neikvæðan ferning, svo jafnan hefur enga lausn.
    Svar: Engin lausn (í mengi rauntalna).
    c. $x^2 = -8x$
    $\displaystyle x^{2} = -8x$
    Flytjum $-8x$ yfir á vinstri hlið (deilum ekki með $x$, þá týnist lausnin $x = 0$):$\displaystyle x^{2} + 8x = 0$
    Tökum $x$ út fyrir sviga:$\displaystyle x^{2} + 8x = x(x + 8)$
    Núllþáttareglan gefur$\displaystyle x = 0 \quad\text{eða}\quad x + 8 = 0$
    svo að$\displaystyle x = 0 \quad\text{eða}\quad x = -8$
    Svar: $x = 0$ eða $x = -8$
    d. $\sqrt{x + 5} = x - 1$
    $\displaystyle \sqrt{x + 5} = x - 1$
    Hefjum báðar hliðar í annað veldi (þetta getur búið til falskar lausnir):$\displaystyle x + 5 = (x - 1)^{2}$
    Margföldum upp úr sviganum:$\displaystyle (x - 1)^{2} = x^{2} - 2x + 1$
    svo að$\displaystyle x + 5 = x^{2} - 2x + 1$
    Flytjum allt yfir á eina hlið:$\displaystyle x^{2} - 3x - 4 = 0$
    Þáttum:$\displaystyle x^{2} - 3x - 4 = (x - 4)(x + 1)$
    Núllþáttareglan gefur$\displaystyle x = 4 \quad\text{eða}\quad x = -1$
    Prófun, $x = 4$:$\displaystyle \text{vinstri hlið: } \sqrt{4 + 5} = 3, \quad \text{hægri hlið: } 4 - 1 = 3, \quad 3 = 3$✓ lausnin stenst.
    Prófun, $x = -1$:$\displaystyle \text{vinstri hlið: } \sqrt{-1 + 5} = 2, \quad \text{hægri hlið: } -1 - 1 = -2, \quad 2 \neq -2$✗ fölsk lausn — höfnum henni.
    Svar: $x = 4$ ($x = -1$ er fölsk lausn)
    e. $x^4 - 22x^2 - 75 = 0$
    Setjum $u = x^2$. Þá er $x^4 = u^2$ og jafnan verður$\displaystyle u^{2} - 22u - 75 = 0$
    Tölurnar $-25$ og $3$ hafa margfeldið $-75$ og summuna $-22$:$\displaystyle u^{2} - 22u - 75 = (u - 25)(u + 3)$
    Núllþáttareglan gefur$\displaystyle u = 25 \quad\text{eða}\quad u = -3$
    $u = x^2$ getur ekki verið neikvætt, svo $u = -3$ gefur enga lausn.
    Skiptum $u$ út fyrir $x^2$:$\displaystyle x^{2} = 25$
    Drögum ferningsrót af báðum hliðum:$\displaystyle x = \pm \sqrt{25} = \pm 5$
    Svar: $x = \pm 5$
    f. $2x^2 + 7 = 169$
    $\displaystyle 2x^{2} + 7 = 169$
    Drögum $7$ frá báðum hliðum:$\displaystyle 2x^{2} = 162$
    Deilum með $2$:$\displaystyle x^{2} = \dfrac{162}{2} = 81$
    Drögum ferningsrót af báðum hliðum:$\displaystyle x = \pm \sqrt{81} = \pm 9$
    Svar: $x = \pm 9$
  2. 2. Notaðu aðferðina „að fylla í ferninginn“ til að leysa jöfnuna $x^2 - 10x + 2 = 0$.
    $\displaystyle x^{2} - 10x + 2 = 0$
    Flytjum fastaliðinn yfir á hægri hlið:$\displaystyle x^{2} - 10x = -2$
    Helmingurinn af stuðli $x$ er $-5$. Bætum $(-5)^2 = 25$ við báðar hliðar:$\displaystyle x^{2} - 10x + 25 = -2 + 25$
    Vinstri hliðin er fullkominn ferningur, $(x - 5)^2$:$\displaystyle (x - 5)^{2} = 23$
    Drögum ferningsrót af báðum hliðum:$\displaystyle x - 5 = \pm \sqrt{23}$
    Leggjum $5$ við báðar hliðar:$\displaystyle x = 5 \pm \sqrt{23}$
    Svar: $x = 5 \pm \sqrt{23}$
  3. 3. Deildu með margliðudeilingu.
    a. $(4x^3 - x^2 + 3) : (x - 1)$
    Deilum fremsta lið með fremsta lið deilisins:$\displaystyle \dfrac{4x^{3}}{x} = 4x^{2}$
    Margföldum deilinn með því:$\displaystyle 4x^{2}(x - 1) = 4x^{3} - 4x^{2}$
    Drögum frá:$\displaystyle \left(4x^{3} - x^{2} + 3\right) - (4x^{3} - 4x^{2}) = 3x^{2} + 3$
    Deilum fremsta lið með fremsta lið deilisins:$\displaystyle \dfrac{3x^{2}}{x} = 3x$
    Margföldum deilinn með því:$\displaystyle 3x(x - 1) = 3x^{2} - 3x$
    Drögum frá:$\displaystyle \left(3x^{2} + 3\right) - (3x^{2} - 3x) = 3x + 3$
    Deilum fremsta lið með fremsta lið deilisins:$\displaystyle \dfrac{3x}{x} = 3$
    Margföldum deilinn með því:$\displaystyle 3(x - 1) = 3x - 3$
    Drögum frá:$\displaystyle \left(3x + 3\right) - (3x - 3) = 6$
    Leifin $6$ er af lægra stigi en deilirinn, svo$\displaystyle \dfrac{4x^{3} - x^{2} + 3}{x - 1} = 4x^{2} + 3x + 3 + \dfrac{6}{x - 1}$
    Svar: $4x^2 + 3x + 3 + \dfrac{6}{x - 1}$
    b. $(5x^3 - 7x^2 - x + 3) : (x - 1)$
    Deilum fremsta lið með fremsta lið deilisins:$\displaystyle \dfrac{5x^{3}}{x} = 5x^{2}$
    Margföldum deilinn með því:$\displaystyle 5x^{2}(x - 1) = 5x^{3} - 5x^{2}$
    Drögum frá:$\displaystyle \left(5x^{3} - 7x^{2} - x + 3\right) - (5x^{3} - 5x^{2}) = -2x^{2} - x + 3$
    Deilum fremsta lið með fremsta lið deilisins:$\displaystyle \dfrac{-2x^{2}}{x} = -2x$
    Margföldum deilinn með því:$\displaystyle -2x(x - 1) = -2x^{2} + 2x$
    Drögum frá:$\displaystyle \left(-2x^{2} - x + 3\right) - (-2x^{2} + 2x) = -3x + 3$
    Deilum fremsta lið með fremsta lið deilisins:$\displaystyle \dfrac{-3x}{x} = -3$
    Margföldum deilinn með því:$\displaystyle -3(x - 1) = -3x + 3$
    Drögum frá:$\displaystyle \left(-3x + 3\right) - (-3x + 3) = 0$
    Leifin $0$ er af lægra stigi en deilirinn, svo$\displaystyle \dfrac{5x^{3} - 7x^{2} - x + 3}{x - 1} = 5x^{2} - 2x - 3$
    Svar: $5x^2 - 2x - 3$
  4. 4. Gefinn er fleygboginn $f(x) = 2x^2 - 14x + 12$.
    a. Finndu jöfnu samhverfuássins (sýndu útreikninga).
    Samhverfuásinn er $x = -\dfrac{b}{2a}$ með $a = 2$ og $b = -14$:$\displaystyle x = \dfrac{-(-14)}{2\cdot 2} = \dfrac{14}{4} = \tfrac{7}{2}$
    Svar: $x = 3{,}5$
    b. Finndu topppunktinn (sýndu útreikninga).
    Topppunkturinn er á samhverfuásnum. Setjum $x = 3{,}5$ inn:$\displaystyle y = 2\cdot (\tfrac{7}{2})^{2} - 14\cdot \tfrac{7}{2} + 12 = \tfrac{49}{2} - 49 + 12 = -\tfrac{25}{2}$
    $a = 2 > 0$, svo fleygboginn opnast upp og topppunkturinn er lægsti punkturinn.
    Svar: $(3{,}5;\ -12{,}5)$
    c. Finndu skurðpunktana við $x$-ás (sýndu útreikninga).
    Á $x$-ás er $y = 0$:$\displaystyle 2x^{2} - 14x + 12 = 0$
    Tökum $2$ út fyrir sviga:$\displaystyle 2x^{2} - 14x + 12 = 2(x^{2} - 7x + 6)$
    Tölurnar $-6$ og $-1$ hafa margfeldið $6$ og summuna $-7$:$\displaystyle x^{2} - 7x + 6 = (x - 6)(x - 1)$
    svo jafnan er$\displaystyle 2(x - 6)(x - 1) = 0$
    Núllþáttareglan gefur$\displaystyle x - 6 = 0 \quad\text{eða}\quad x - 1 = 0$
    svo að$\displaystyle x = 6 \quad\text{eða}\quad x = 1$
    Svar: $(1, 0)$ og $(6, 0)$
    d. Finndu skurðpunktinn við $y$-ás.
    Á $y$-ás er $x = 0$:$\displaystyle y = 2\cdot 0^{2} - 14\cdot 0 + 12 = 12$
    Svar: $(0, 12)$
    e. Teiknaðu fleygbogann eins nákvæmlega og þú getur (finndu aukapunkta).
    Merkjum skurðpunktana og topppunktinn úr a–d lið. Reiknum nokkra aukapunkta:
    $\displaystyle f(3) = 2\cdot 3^{2} - 14\cdot 3 + 12 = 18 - 42 + 12 = -12$
    $\displaystyle f(4) = 2\cdot 4^{2} - 14\cdot 4 + 12 = 32 - 56 + 12 = -12$
    $\displaystyle f(7) = 2\cdot 7^{2} - 14\cdot 7 + 12 = 98 - 98 + 12 = 12$
    Fleygboginn er samhverfur um $x = 3{,}5$, svo hver punktur á sér spegilmynd hinum megin við ásinn. Teiknum slétta sveigju í gegnum alla punktana.
    Svar: Sjá mynd.
  5. 5. Leirdúfu er skotið af palli. Leirdúfan flýgur eftir ferlinum $$y = 4 + 5x - 0{,}5x^2$$ þar sem $x$ er fjarlægð frá skotstað og $y$ er hæð leirdúfunnar, hvort tveggja í metrum.
    a. Úr hvaða hæð er leirdúfunni skotið?
    Skotið er þar sem $x = 0$:$\displaystyle y = 4 + 5\cdot 0 - 0{,}5\cdot 0^{2} = 4$
    Svar: $4$ m
    b. Hver er mesta hæðin sem leirdúfan nær?
    Hæsta staðan er á samhverfuásnum $x = -\dfrac{b}{2a}$, hér með $a = -0{,}5$ og $b = 5$:$\displaystyle x = \dfrac{-5}{2\cdot (-0{,}5)} = \dfrac{-5}{-1} = 5$
    Hæðin þar:$\displaystyle y = 4 + 5\cdot 5 - 0{,}5\cdot 5^{2} = 4 + 25 - 12{,}5 = 16{,}5$
    $a = -0{,}5 < 0$, svo fleygboginn opnast niður og þetta er hæsti punkturinn.
    Svar: $16{,}5$ m
    c. Hve langt frá pallinum er leirdúfan þegar hún lendir á jörðinni?
    Leirdúfan lendir þegar $y = 0$:$\displaystyle 4 + 5x - 0{,}5x^{2} = 0$
    Margföldum báðar hliðar með $-2$:$\displaystyle x^{2} - 10x - 8 = 0$
    $\displaystyle a = 1,\quad b = -10,\quad c = -8$
    Aðgreinirinn:$\displaystyle d = (-10)^{2} - 4\cdot 1\cdot (-8) = 100 + 32 = 132$
    Lausnarformúlan gefur$\displaystyle x = \dfrac{10 \pm \sqrt{132}}{2}$
    Einföldum rótina:$\displaystyle \sqrt{132} = \sqrt{4\cdot 33} = 2\sqrt{33}$
    Styttum með $2$:$\displaystyle x = 5 \pm \sqrt{33}$
    $x = 5 - \sqrt{33} \approx -0{,}74$ er neikvæð og kemur ekki til greina sem fjarlægð. Því er $x = 5 + \sqrt{33} \approx 10{,}74$.
    Svar: $x \approx 10{,}74$ m
  6. 6. Fyrir hvaða gildi á $c$ hefur jafnan $x^2 - 9x + c = 0$ tvær rauntölulausnir?
    Hér er $a = 1$, $b = -9$ og fastaliðurinn $c$. Aðgreinirinn $d = b^2 - 4ac$ er$\displaystyle d = (-9)^{2} - 4c = 81 - 4c$
    Jafnan hefur tvær rauntölulausnir þegar $d > 0$:$\displaystyle 81 - 4c > 0$
    Leggjum $4c$ við báðar hliðar:$\displaystyle 81 > 4c$
    Deilum með $4$:$\displaystyle c < 20{,}25$
    Svar: $c < 20{,}25$
  7. 7. Gefið er að $f(x) = x^2 + bx + c$ hefur núllstöðvarnar $x = -2$ og $x = 9$. Hver er margliðan?
    Fyrst $x = -2$ og $x = 9$ eru núllstöðvar, eru $x + 2$ og $x - 9$ þættir í $f(x)$, og stuðull $x^2$ er $1$:
    $\displaystyle f(x) = (x + 2)(x - 9)$
    Margföldum upp úr svigunum:$\displaystyle (x + 2)(x - 9) = x^{2} - 9x + 2x - 18 = x^{2} - 7x - 18$
    Þá er $b = -7$ og $c = -18$.
    Svar: $f(x) = x^2 - 7x - 18$
  8. 8. Finndu afganginn (leifina) þegar $(x + 6)$ er deilt upp í margliðuna $2x^3 + 5x^2 - 3x + 4$.
    Leifareglan: leifin þegar $f(x)$ er deilt með $x - a$ er $f(a)$. Deilirinn er $x + 6 = x - (-6)$, svo $a = -6$.
    $\displaystyle f(-6) = 2\cdot (-6)^{3} + 5\cdot (-6)^{2} - 3\cdot (-6) + 4 = -432 + 180 + 18 + 4 = -230$
    Svar: $-230$
  9. 9. Leystu ójöfnuna $(x + 6)(x - 1)(x + 2) \geq 0$. Svaraðu bæði með lausnargrafi og biltáknum.
    Núllstöðvar þáttanna:$\displaystyle x + 6 = 0 \quad\text{eða}\quad x - 1 = 0 \quad\text{eða}\quad x + 2 = 0$
    þ.e.$\displaystyle x = -6 \quad\text{eða}\quad x = -2 \quad\text{eða}\quad x = 1$
    Formerkjamynd:
    $x$$-6$$-2$$1$
    $x + 6$−0+++++
    $x - 1$−−−−−0+
    $x + 2$−−−0+++
    $f(x)$−0+0−0+
    $\geq 0$: þar sem neðsta línan sýnir $+$ eða $0$:$\displaystyle -6 \leq x \leq -2 \quad\text{eða}\quad x \geq 1$
    Svar: $\mathopen{[}{-6},\ {-2}\mathclose{]}$ eða $\mathopen{[}{1},\ \infty\mathclose{[}$
  10. 10. Leystu ójöfnuna $(x + 3)^2(x - 1)^3(x + 6) \leq 0$. Svaraðu bæði með lausnargrafi og biltáknum.
    Núllstöðvar þáttanna:$\displaystyle (x + 3)^{2} = 0 \quad\text{eða}\quad (x - 1)^{3} = 0 \quad\text{eða}\quad x + 6 = 0$
    þ.e.$\displaystyle x = -6 \quad\text{eða}\quad x = -3 \quad\text{eða}\quad x = 1$
    Formerkjamynd:
    $x$$-6$$-3$$1$
    $(x + 3)^{2}$+++0+++
    $(x - 1)^{3}$−−−−−0+
    $x + 6$−0+++++
    $f(x)$+0−0−0+
    Þátturinn $(x + 3)^2$ er aldrei neikvæður (slétt veldi), svo formerkið skiptir ekki um við $x = -3$; $(x - 1)^3$ hefur sama formerki og $x - 1$.
    $\leq 0$: þar sem neðsta línan sýnir $-$ eða $0$:$\displaystyle -6 \leq x \leq 1$
    Svar: $\mathopen{[}{-6},\ {1}\mathclose{]}$
  11. 11. Leystu jöfnuna $x^3 + 3x^2 - 13x - 15 = 0$.
    Köllum vinstri hliðina $f(x)$. Heiltölulausnir eru deilar fastaliðarins $-15$: $\pm1, \pm3, \pm5, \pm15$. Prófum:
    $\displaystyle f(1) = 1^{3} + 3\cdot 1^{2} - 13\cdot 1 - 15 = -24$$\neq 0$
    $\displaystyle f(-1) = (-1)^{3} + 3\cdot (-1)^{2} - 13\cdot (-1) - 15 = 0$svo $x + 1$ er þáttur.
    Deilum með $x + 1$ (stuðlaaðferð, $a = -1$):
    $-1$$1$$3$$-13$$-15$
    $-1$$-2$$15$
    $1$$2$$-15$$0$
    Kvóti $x^2 + 2x - 15$, leif $0$.
    svo að$\displaystyle x^{3} + 3x^{2} - 13x - 15 = (x + 1)(x^{2} + 2x - 15)$
    Þáttum annars stigs þáttinn: tölurnar $-3$ og $5$ hafa margfeldið $-15$ og summuna $2$:$\displaystyle x^{2} + 2x - 15 = (x - 3)(x + 5)$
    Jafnan er því$\displaystyle (x + 1)(x - 3)(x + 5) = 0$
    Núllþáttareglan gefur$\displaystyle x = -1 \quad\text{eða}\quad x = 3 \quad\text{eða}\quad x = -5$
    Svar: $x = -5$ eða $x = -1$ eða $x = 3$
  12. 12. Gefin er margliðan $f(x) = x^3 - x^2 - 10x - 8$.
    a. Finndu leifina (afganginn) ef deilt er í margliðuna með $x + 1$.
    Deilum með $x + 1$ (stuðlaaðferð, $a = -1$):
    $-1$$1$$-1$$-10$$-8$
    $-1$$2$$8$
    $1$$-2$$-8$$0$
    Kvóti $x^2 - 2x - 8$, leif $0$.
    Til staðfestingar, með leifareglunni:$\displaystyle f(-1) = (-1)^{3} - (-1)^{2} - 10\cdot (-1) - 8 = -1 - 1 + 10 - 8 = 0$
    Svar: $0$
    b. Fullþáttaðu margliðuna.
    Leifin í a-lið er $0$, svo $x + 1$ er þáttur og kvótinn er hinn þátturinn:$\displaystyle x^{3} - x^{2} - 10x - 8 = (x + 1)(x^{2} - 2x - 8)$
    Tölurnar $2$ og $-4$ hafa margfeldið $-8$ og summuna $-2$:$\displaystyle x^{2} - 2x - 8 = (x + 2)(x - 4)$
    svo að$\displaystyle x^{3} - x^{2} - 10x - 8 = (x + 1)(x + 2)(x - 4)$
    Svar: $f(x) = (x + 1)(x + 2)(x - 4)$
    c. Leystu jöfnuna $x^3 - x^2 - 10x - 8 = 0$ (notaðu þáttunina í b-lið).
    Með þáttuninni úr b-lið verður jafnan$\displaystyle (x + 1)(x + 2)(x - 4) = 0$
    Núllþáttareglan gefur$\displaystyle x + 1 = 0 \quad\text{eða}\quad x + 2 = 0 \quad\text{eða}\quad x - 4 = 0$
    svo að$\displaystyle x = -2 \quad\text{eða}\quad x = -1 \quad\text{eða}\quad x = 4$
    Svar: $x = -2$ eða $x = -1$ eða $x = 4$
