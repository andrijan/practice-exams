Formúlur

Núllþáttareglan: ef $a \cdot b = 0$ þá er $a = 0$ eða $b = 0$.
Lausnarformúlan: $ax^2 + bx + c = 0$ hefur lausnirnar $x = \dfrac{-b \pm \sqrt{d}}{2a}$ þar sem $d = b^2 - 4ac$. Ef $d > 0$ eru lausnirnar tvær, ef $d = 0$ ein og ef $d < 0$ engin.
Fleygboginn $y = ax^2 + bx + c$: samhverfuás $x = -\dfrac{b}{2a}$; opnast upp ef $a > 0$, niður ef $a < 0$.
Leifareglan: leifin þegar $f(x)$ er deilt með $x - a$ er $f(a)$.
Þáttunarreglan: ef $f(a) = 0$ þá er $x - a$ þáttur í $f(x)$.

Lausnir

Æfing 4.1 – Annars stigs jöfnur án fyrsta stigs liðar

  1. 3. $5x^2 + 20 = 0$
    Flytjum $20$ yfir:$\displaystyle 5x^{2} = -20$
    Deilum með $5$:$\displaystyle x^{2} = -4$
    Ferningur rauntölu getur aldrei verið neikvæður, svo jafnan hefur enga lausn í mengi rauntalna.
    Svar: Engin rauntölulausn.
  2. 6. $54 - 3x^2 = 0$
    Flytjum $54$ yfir:$\displaystyle -3x^{2} = -54$
    Deilum með $-3$:$\displaystyle x^{2} = 18$
    Drögum ferningsrót af báðum hliðum:$\displaystyle x = \pm \sqrt{18}$
    Einföldum rótina:$\displaystyle \sqrt{18} = \sqrt{9\cdot 2} = 3\sqrt{2}$
    svo að$\displaystyle x = \pm 3\sqrt{2}$
    Svar: $x = \pm 3\sqrt{2}$
  3. 8. $(x-6)^2 = 25$
    Drögum ferningsrót af báðum hliðum:$\displaystyle x - 6 = \pm \sqrt{25} = \pm 5$
    þ.e.$\displaystyle x = 6 \pm 5$
    svo að$\displaystyle x = 6 + 5 = 11 \quad\text{eða}\quad x = 6 - 5 = 1$
    Svar: $x = 1$ eða $x = 11$
  4. 10. $(2x-3)^2 - 81 = 0$
    Flytjum $81$ yfir:$\displaystyle (2x - 3)^{2} = 81$
    Drögum ferningsrót af báðum hliðum:$\displaystyle 2x - 3 = \pm \sqrt{81} = \pm 9$
    Leggjum $3$ við:$\displaystyle 2x = 3 \pm 9$
    þ.e.$\displaystyle 2x = 12 \quad\text{eða}\quad 2x = -6$
    svo að$\displaystyle x = 6 \quad\text{eða}\quad x = -3$
    Svar: $x = 6$ eða $x = -3$

Æfing 4.2 – Lausn með þáttun

  1. 2. $3x^2 - 15x = 0$
    Tökum $3x$ út fyrir sviga:$\displaystyle 3x^{2} - 15x = 3x(x - 5)$
    $\displaystyle 3x(x - 5) = 0$
    Núllþáttareglan gefur$\displaystyle 3x = 0 \quad\text{eða}\quad x - 5 = 0$
    svo að$\displaystyle x = 0 \quad\text{eða}\quad x = 5$
    Svar: $x = 0$ eða $x = 5$
  2. 12. $-x^2 + 2x + 8 = 0$
    Margföldum báðar hliðar með $-1$:$\displaystyle x^{2} - 2x - 8 = 0$
    Tölurnar $-4$ og $2$ hafa margfeldið $-8$ og summuna $-2$:$\displaystyle x^{2} - 2x - 8 = (x - 4)(x + 2)$
    $\displaystyle (x - 4)(x + 2) = 0$
    Núllþáttareglan gefur$\displaystyle x - 4 = 0 \quad\text{eða}\quad x + 2 = 0$
    svo að$\displaystyle x = 4 \quad\text{eða}\quad x = -2$
    Svar: $x = 4$ eða $x = -2$
  3. 18. $9x^2 + 30x + 25 = 0$
    Vinstri hliðin er fullkominn ferningur:$\displaystyle 9x^{2} + 30x + 25 = (3x)^{2} + 2\left(3x\right)\cdot 5 + 5^{2} = (3x + 5)^{2}$
    $\displaystyle (3x + 5)^{2} = 0$
    þ.e.$\displaystyle 3x + 5 = 0$
    $\displaystyle 3x = -5$
    svo að$\displaystyle x = -\tfrac{5}{3}$
    Þetta er tvöföld lausn.
    Svar: $x = -\tfrac{5}{3}$
  4. 20. $4x^2 + 4x - 35 = 0$
    Leitum að tveimur tölum með margfeldið $a\cdot c$ og summuna $b = 4$:$\displaystyle 4\cdot (-35) = -140$
    $14$ og $-10$ duga, því$\displaystyle 14\cdot (-10) = -140$og $14 + (-10) = 4$.
    Skiptum miðliðnum upp:$\displaystyle 4x^{2} + 4x - 35 = 4x^{2} + 14x - 10x - 35$
    Tökum sameiginlega þætti út:$\displaystyle 4x^{2} + 14x - 10x - 35 = 2x(2x + 7) - 5(2x + 7) = (2x - 5)(2x + 7)$
    $\displaystyle (2x - 5)(2x + 7) = 0$
    Núllþáttareglan gefur$\displaystyle 2x - 5 = 0 \quad\text{eða}\quad 2x + 7 = 0$
    svo að$\displaystyle x = \tfrac{5}{2} \quad\text{eða}\quad x = -\tfrac{7}{2}$
    Svar: $x = \tfrac{5}{2}$ eða $x = -\tfrac{7}{2}$
  5. 24. $5x^2 - 5x - 30 = 0$
    Deilum báðum hliðum með $5$:$\displaystyle x^{2} - x - 6 = 0$
    Tölurnar $-3$ og $2$ hafa margfeldið $-6$ og summuna $-1$:$\displaystyle x^{2} - x - 6 = (x - 3)(x + 2)$
    Núllþáttareglan gefur$\displaystyle x - 3 = 0 \quad\text{eða}\quad x + 2 = 0$
    svo að$\displaystyle x = 3 \quad\text{eða}\quad x = -2$
    Svar: $x = 3$ eða $x = -2$
  6. 26. $-\tfrac{1}{3}x^2 + \tfrac{1}{2}x - \tfrac{3}{16} = 0$
    Margföldum báðar hliðar með $-48$ til að losna við brotin:$\displaystyle 16x^{2} - 24x + 9 = 0$
    Vinstri hliðin er fullkominn ferningur:$\displaystyle 16x^{2} - 24x + 9 = (4x)^{2} - 2\left(4x\right)\cdot 3 + 3^{2} = (4x - 3)^{2}$
    $\displaystyle (4x - 3)^{2} = 0$
    þ.e.$\displaystyle 4x - 3 = 0$
    svo að$\displaystyle x = \tfrac{3}{4}$
    Þetta er tvöföld lausn.
    Svar: $x = \tfrac{3}{4}$

Æfing 4.3 – Að fylla í ferninginn

  1. 1. $x^2 - 6x + 4 = 0$
    Flytjum fastann yfir:$\displaystyle x^{2} - 6x = -4$
    Helmingur af stuðli $x$ er $-3$ og $(-3)^2 = 9$. Bætum $9$ við báðar hliðar:$\displaystyle x^{2} - 6x + 9 = -4 + 9$
    Vinstri hliðin er nú fullkominn ferningur:$\displaystyle x^{2} - 6x + 9 = (x - 3)^{2}$
    svo að$\displaystyle (x - 3)^{2} = 5$
    Drögum ferningsrót af báðum hliðum:$\displaystyle x - 3 = \pm \sqrt{5}$
    þar af leiðandi$\displaystyle x = 3 \pm \sqrt{5}$
    Svar: $x = 3 \pm \sqrt{5}$
  2. 3. $x^2 - 4x + 7 = 0$
    Flytjum fastann yfir:$\displaystyle x^{2} - 4x = -7$
    Helmingur af $-4$ er $-2$ og $(-2)^2 = 4$. Bætum $4$ við báðar hliðar:$\displaystyle x^{2} - 4x + 4 = -7 + 4$
    þ.e.$\displaystyle (x - 2)^{2} = -3$
    Ferningur getur ekki verið neikvæður, svo jafnan hefur enga rauntölulausn.
    Svar: Engin rauntölulausn.
  3. 5. $x^2 + 3x = 5$
    Helmingur af $3$ er $\tfrac32$ og $\left(\tfrac32\right)^2 = \tfrac94$. Bætum $\tfrac94$ við báðar hliðar:$\displaystyle x^{2} + 3x + \tfrac{9}{4} = 5 + \tfrac{9}{4}$
    Vinstri hliðin er fullkominn ferningur:$\displaystyle x^{2} + 3x + \tfrac{9}{4} = (x + \tfrac{3}{2})^{2}$
    Hægri hliðin:$\displaystyle 5 + \tfrac{9}{4} = \tfrac{20}{4} + \tfrac{9}{4} = \tfrac{29}{4}$
    svo að$\displaystyle (x + \tfrac{3}{2})^{2} = \tfrac{29}{4}$
    Drögum ferningsrót af báðum hliðum:$\displaystyle x + \tfrac{3}{2} = \pm \sqrt{\tfrac{29}{4}} = \pm \dfrac{\sqrt{29}}{2}$
    þar af leiðandi$\displaystyle x = -\tfrac{3}{2} \pm \dfrac{\sqrt{29}}{2} = \dfrac{-3 \pm \sqrt{29}}{2}$
    Svar: $x = \dfrac{-3 \pm \sqrt{29}}{2}$
  4. 6. $-x^2 - 6x + 2 = 0$
    Margföldum með $-1$ svo stuðull $x^2$ verði $1$:$\displaystyle x^{2} + 6x - 2 = 0$
    Flytjum fastann yfir:$\displaystyle x^{2} + 6x = 2$
    Helmingur af $6$ er $3$ og $3^2 = 9$. Bætum $9$ við báðar hliðar:$\displaystyle x^{2} + 6x + 9 = 2 + 9$
    Vinstri hliðin er fullkominn ferningur:$\displaystyle x^{2} + 6x + 9 = (x + 3)^{2}$
    svo að$\displaystyle (x + 3)^{2} = 11$
    Drögum ferningsrót af báðum hliðum:$\displaystyle x + 3 = \pm \sqrt{11}$
    þar af leiðandi$\displaystyle x = -3 \pm \sqrt{11}$
    Svar: $x = -3 \pm \sqrt{11}$
  5. 10. $2x^2 + 5x - 1 = 0$
    Deilum með $2$ svo stuðull $x^2$ verði $1$:$\displaystyle x^{2} + \tfrac{5}{2}x - \tfrac{1}{2} = 0$
    Flytjum fastann yfir:$\displaystyle x^{2} + \tfrac{5}{2}x = \tfrac{1}{2}$
    Helmingur af $\tfrac52$ er $\tfrac54$ og $\left(\tfrac54\right)^2 = \tfrac{25}{16}$. Bætum því við báðar hliðar:$\displaystyle x^{2} + \tfrac{5}{2}x + \tfrac{25}{16} = \tfrac{1}{2} + \tfrac{25}{16}$
    Vinstri hliðin er fullkominn ferningur:$\displaystyle x^{2} + \tfrac{5}{2}x + \tfrac{25}{16} = (x + \tfrac{5}{4})^{2}$
    Hægri hliðin:$\displaystyle \tfrac{1}{2} + \tfrac{25}{16} = \tfrac{8}{16} + \tfrac{25}{16} = \tfrac{33}{16}$
    svo að$\displaystyle (x + \tfrac{5}{4})^{2} = \tfrac{33}{16}$
    Drögum ferningsrót af báðum hliðum:$\displaystyle x + \tfrac{5}{4} = \pm \sqrt{\tfrac{33}{16}} = \pm \dfrac{\sqrt{33}}{4}$
    þar af leiðandi$\displaystyle x = -\tfrac{5}{4} \pm \dfrac{\sqrt{33}}{4} = \dfrac{-5 \pm \sqrt{33}}{4}$
    Svar: $x = \dfrac{-5 \pm \sqrt{33}}{4}$

Æfing 4.4 A – Lausnarformúlan

  1. 4. $-x^2 + 3x + 2 = 0$
    Jafnan er á staðlaða forminu $ax^2 + bx + c = 0$ með$\displaystyle -x^{2} + 3x + 2 = 0$
    $\displaystyle a = -1,\quad b = 3,\quad c = 2$
    Aðgreinirinn $d = b^2 - 4ac$:$\displaystyle d = 3^{2} - 4\cdot (-1)\cdot 2 = 9 + 8 = 17$
    Lausnarformúlan $x = \dfrac{-b \pm \sqrt{d}}{2a}$ gefur$\displaystyle x = \dfrac{-3 \pm \sqrt{17}}{2\cdot (-1)} = \dfrac{-3 \pm \sqrt{17}}{-2}$
    Margföldum teljara og nefnara með $-1$:$\displaystyle x = \dfrac{3 \pm \sqrt{17}}{2}$
    Svar: $x = \dfrac{3 \pm \sqrt{17}}{2}$
  2. 6. $2 - 4x - x^2 = 0$
    Röðum liðunum eftir veldum:$\displaystyle -x^{2} - 4x + 2 = 0$
    svo að$\displaystyle a = -1,\quad b = -4,\quad c = 2$
    Aðgreinirinn:$\displaystyle d = (-4)^{2} - 4\cdot (-1)\cdot 2 = 16 + 8 = 24$
    Einföldum rótina:$\displaystyle \sqrt{24} = \sqrt{4\cdot 6} = 2\sqrt{6}$
    Lausnarformúlan gefur$\displaystyle x = \dfrac{-(-4) \pm 2\sqrt{6}}{2\cdot (-1)} = \dfrac{4 \pm 2\sqrt{6}}{-2}$
    Deilum hvorum lið með $-2$:$\displaystyle x = -2 \pm \sqrt{6}$
    Svar: $x = -2 \pm \sqrt{6}$
  3. 10. $-x(3x-5) + 2 = 6x$
    Margföldum upp úr sviganum:$\displaystyle -x(3x - 5) + 2 = -3x^{2} + 5x + 2$
    svo jafnan er$\displaystyle -3x^{2} + 5x + 2 = 6x$
    Flytjum $6x$ yfir:$\displaystyle -3x^{2} - x + 2 = 0$
    Margföldum með $-1$:$\displaystyle 3x^{2} + x - 2 = 0$
    $\displaystyle a = 3,\quad b = 1,\quad c = -2$
    Aðgreinirinn:$\displaystyle d = 1^{2} - 4\cdot 3\cdot (-2) = 1 + 24 = 25$
    Lausnarformúlan gefur$\displaystyle x = \dfrac{-1 \pm \sqrt{25}}{2\cdot 3} = \dfrac{-1 \pm 5}{6}$
    þ.e.$\displaystyle x = \dfrac{4}{6} = \tfrac{2}{3} \quad\text{eða}\quad x = \dfrac{-6}{6} = -1$
    Svar: $x = \tfrac{2}{3}$ eða $x = -1$
  4. 19. Fyrir hvaða gildi á $c$ hefur jafnan $3x^2 - c = 0$ enga rauntölulausn?
    Hér er $a = 3$, $b = 0$ og fastaliðurinn $-c$. Aðgreinirinn:$\displaystyle d = 0^{2} - 4\cdot 3\cdot (-c) = 12c$
    Jafnan hefur enga rauntölulausn þegar $d < 0$:$\displaystyle 12c < 0$
    Deilum með $12$:$\displaystyle c < 0$
    Svar: $c < 0$
  5. 20. Fyrir hvaða gildi á $c$ hefur jafnan $x^2 - 6x + c = 0$ enga rauntölulausn?
    $a = 1$, $b = -6$ og fastaliðurinn $c$. Aðgreinirinn:$\displaystyle d = (-6)^{2} - 4\cdot 1c = 36 - 4c$
    Enga rauntölulausn þegar $d < 0$:$\displaystyle 36 - 4c < 0$
    Leggjum $4c$ við:$\displaystyle 36 < 4c$
    Deilum með $4$:$\displaystyle c > 9$
    Svar: $c > 9$
